# 墙面爬梯插件（第一版）

`wall_ladder.py` 在 Bentley OpenPlant Modeler / MicroStation 的活动 3D 模型中，沿用户点选的一条**竖直线**创建**墙面爬梯**。

## 几何约定

所选竖直线同时代表两件事（与图纸 `FACE OF CONCRETE` 一致）：

1. **墙面**（Face of Concrete）；以及
2. **爬梯正中心在墙面上的投影线**。

因此爬梯位于该线所在的竖直平面，并向"出梯方向"一侧伸出：

- 两根立柱（Ladder Stile）为**扁钢**，中心线距墙面 **220**；
- 横担（Rung）为 **φ24** 圆钢，两端各突出立柱外侧面 **10**；
- 最低一节横担距竖直线最低点 **400**，其余横担间距在 **250（首选）～300** 之间自动分配；
- 沿高度按固定间距（默认 1500）设置简单墙面支架（横撑 + 墙面贴板）；
- 平台（＝所选竖直线顶部）以上，**立柱与护笼再延长 1200**（标准 5.2.6），该段不设踏步；
- 可选**防护围栏（护笼）**：沿爬梯外侧的 11 点扁钢路径扫掠成环 + 均布竖杆，具体见下节。

由于一条竖直线本身无法确定墙面法向，出梯方向由界面参数**水平角**给出（`0° = +X`，`90° = +Y`）。

### 护笼（防护围栏）

- 水平剖视：以扁钢截面沿 **11 点折线路径**（10 段，含两段 90° 圆头弧）**扫掠**成一个环。
- 默认（梯宽 400、立柱中心距墙 220）路径关键点坐标（`n`=出梯、`t`=宽度）：

  `(220,200) → (220,140) → (115,140) → (115,355) → (630,355) → 圆头 (985,0) → (630,−355) → (115,−355) → (115,−140) → (220,−140) → (220,−200)`

  - 起、终点为两根立柱的**几何中心** `(220, ±梯宽/2)`；
  - 端头回环：沿 `t` 往梯子中心 **60**（`CAGE_TAB_INWARD`）、再沿 `n` 往墙面 **105**（`CAGE_HOOK_N_INWARD`）、再沿 `t` 向外到护笼半宽；
  - 两侧直段在 `t = ±护笼半宽 = ±355`（`CAGE_HALF_WIDTH`，即图纸 **R355**）；
  - 圆头为两段 90° 圆弧，半径 = 护笼半宽，顶点在 `踏步中心 + 410 + 355`（`CAGE_STRAIGHT_END_OFFSET`）。
- 每环吸附到最近的踏步：环中心 `z = 踏步 z − 踏步半径 − 半个环宽`，即**环顶紧贴踏步底面**；相邻环间距不超过 1500（`CAGE_HOOP_SPACING` 为最大值，不是定值）。
- 平台（＝所选竖直线顶部＝攀爬高度）以上 **1200**（`TOP_EXTENSION`）为延长段：没有踏步，护笼按 ≤1500 的间距补环，最顶一环的环顶与立柱顶端齐平；竖杆同步延长。
- **最顶（倒 L + 顶环）**：与其他环不同，**倒 L 与顶环由一条 9 点路径、同一根 50×5 扁钢扫掠而成**（角点坐标系：原点＝所选竖直线最高点/平台面，`h` 向上）。9 点 `(n, t, h)`：

  `(−700, −355, 0) → (−700, −355, 1200) → (115, −355, 1175) → (630, −355, 1175) → 圆头 (985, 0, 1175) → (630, +355, 1175) → (115, +355, 1175) → (−700, +355, 1200) → (−700, +355, 0)`

  - 倒 L 竖段在 `n=-700`、`t=±355`，自平台面到立柱顶；横段折到顶环最外侧边（`t=±355`、`n=115`）；
  - 顶环中线在 `h=+1175`（＝立柱顶 1200 − 半个环宽，环顶与立柱顶齐平），圆头为两段 90° 弧、半径 355。
- 该路径按**扫掠**建模（会依次尝试 6 参数 / 10 参数 × 多种参考方向 / 正反两个方向）；若内核 `BodyFromSweep` 全部失败，才退回“逐段扁钢实体块”（圆弧按 7.5° 折线近似）。

### 立柱扁钢选型表

| 扁钢 | MAX SUPPORT CENTRES |
| --- | --- |
| 75×12 FLAT | 4500 mm |
| 75×16 FLAT | 5500 mm |
| 75×20 FLAT | 6000 mm |

映射规则：所选竖直线长度（视为**支架跨距**）`≤4500 → 75×12`、`≤5500 → 75×16`、`≤6000 → 75×20`；超过 6000 时拒绝，要求增设中间支承。也可在编程调用时用 `stile_flat=(宽, 厚)` 显式覆盖。

## 建模假定

- 所选线段即**墙面 + 爬梯中心投影线**；顶点为爬梯的落地端与顶端。
- **立柱扁钢按竖直线长度选型**：本版把所选竖直线长度当作两端支承之间的跨距。中间支架视为墙面拉结，不改变选型跨距；若现场把中间支架也当结构支承，请直接显式指定 `stile_flat`。
- 立柱扁钢的 **75 宽面沿出梯方向**（前后），厚度（12/16/20）沿爬梯宽度方向，故横担从侧面外伸 10。
- 横担**不建模端部回弯**（图纸中的 40 mm 下弯）、不钻孔，仅按 φ24 圆钢穿过立柱中心面建模。
- 立柱顶端比**最顶一节横担**高 50 mm（`TOP_RUNG_CLEARANCE`），因此踏步不冒出立柱；立柱长度仍等于所选竖直线长度。
- 出梯方向由**水平角**近似，适用于任意朝向的竖直墙面；不读取墙面的真实法向。
- 中间支架为 **75×10 角钢**：长度沿出梯方向从墙面伸到立柱前缘（约 258），一肢竖直、一肢水平，L 开口朝外；竖直肢平面贴立柱外侧面（背靠背）。墙端焊一块平行墙面的 **100×100×10** 钢板，**只建板、不建螺栓/锚固**；钢板中心与 75 角钢截面中心对齐。
- **两端不设中间支架**：最低点视为直接固定到地面（落地件不在本版范围），最高点视为与顶部平台连接。
- 护笼半宽取图纸 **R355**（固定 `CAGE_HALF_WIDTH=355`）；起、终点落在两根立柱的**几何中心**，端头以水平回环绕立柱（沿 `t` 60、沿 `n` 105）。
- 护笼竖杆只布置在**立柱以外的外圈**（跳过两端绕立柱的回环），沿外圈等弧长均布；竖杆贴在环的外表面。
- 构件之间不做布尔相并；生成时**爬梯、护笼分别组装成一个普通单元**（`WALL_LADDER` / `WALL_LADDER_CAGE`），角钢两肢与贴墙板、竖杆与环之间有重叠，仅作视觉连接。

## 使用方法

1. 在 OpenPlant Modeler 中打开一个**三维** DGN 模型。
2. 打开 Python Editor，运行 `wall_ladder.py`。
3. 在面板中设置爬梯宽度、立柱中心线距墙、最低横担离地、墙面支架间距、出梯方向角，并勾选是否加**防护围栏（护笼）**。
4. 点选一条**竖直线**（视为墙面），程序即时生成预览；改参数会自动重建一版。
5. 点【确定】保留预览；点【取消】删除本次预览。

生成结果按**两个普通单元**给出：**爬梯** `WALL_LADDER`（立柱 + 横担 + 中间支架）与**护笼** `WALL_LADDER_CAGE`（环 + 竖杆 + 最顶倒 L/顶环），可分别选中、隐藏或统计。参数变化时采用"先成功创建新版、再删除旧版"的方式重建，因此几何创建失败不会误删上一版有效预览。

## 几何规则

- 建立正交基：`n` 为出梯方向（水平），`t = z × n` 为宽度方向，`z` 竖直向上，满足 `n × t = z`。
- 立柱中心位于 `n = 220`、`t = ±宽度/2`；横担中心位于 `n = 220`，长度 = `宽度 + 立柱厚 + 2×10`。
- 横担分层在 `[250, 300]` 内按区间均匀分配，最高一节停在竖直线顶部以下 50（`TOP_RUNG_CLEARANCE`）；高度不足时只放最低一节。极短爬梯可能出现无法同时满足上下限的区间，此时优先取越界更小的分法。
- 中间支架只出现在两端之间：从 `支架间距` 起、按间距排布，严格低于竖直线顶部；最低点与最高点都不设支架。
- 护笼路径（局部平面，11 点）：立柱中心 →(t 内 60)→ →(n 向墙 105)→ →(t 外到 ±355)→ →(n 到 630)→ 两段 90° 圆弧（半径 355）绕过圆头 → 对称返回另一立柱中心。
- 护笼环用扁钢 `50×5` 截面（竖直 50）沿该路径**扫掠**；竖杆 `30×5` 在相邻环之间，沿外圈（跳过两端回环）等弧长均布 11 根。
- 竖直线校验：所有顶点的水平偏差不得超过 5 mm，且必须为单条开放线段。

## 已知限制（第一版）

- 不建模：顶部扶手 / 延伸段、落地踏步 / 平台、锚栓与化学螺栓、预埋件、焊缝。
- 护笼环与梯顶、地面的收口（顶部封口环、底部加强）未单独处理；环只按间距排到梯顶。
- 护笼与爬梯、环与竖杆之间不做布尔并集。
- 不建模横担端部回弯（图纸 40）、不按孔径开孔。
- 剖面圆角、立柱端部切角等细部从简。
- 构件之间不做布尔相并；如需整体实体，可在生成后自行并集。

## 调用方式

- 界面入口：`PyMain()`（脚本末尾有 `if __name__ == "__main__"`，在 Python Editor 中直接运行）。
- 编程调用：
  - `draw_wall_ladder(base_point, top_point, outward=(1, 0), **params)`：直接生成并写入模型，返回单元句柄列表（`WALL_LADDER`、`WALL_LADDER_CAGE`）；
  - `build_ladder_layout(height_mm, **params)`：纯函数，返回毫米级构件布局（可在无 MicroStation 环境下测试）；
  - `select_stile_flat(span_mm)`：按支架跨距返回 `(宽, 厚)`；
  - `compute_rung_levels(height_mm, ...)` / `compute_bracket_levels(height_mm, ...)`：横担 / 支架分层；
  - `build_cage_layout(width, rung_levels, rung_diameter, ...)`：护笼环路径、竖杆站位与构件（纯函数）；
  - `build_cage_hoop_path(...)`：普通环（带回环）路径；
  - `build_cage_top_path(...)`：最顶「倒 L + 顶环」9 点路径；
  - `cage_station_points(...)`：竖杆沿路径均布。

## 几何自检

`_wall_ladder_selftest.py` 用 AST 抽取纯几何函数，**不需要 MicroStation**，任何 Python 3 都能跑：

```
python _wall_ladder_selftest.py
```

覆盖：立柱扁钢选型边界、横担分层（最低 400、间距落在 250～300、顶节低于立柱顶端 50）、中间支架分层（两端不设）、正交基 `n × t = z`、平台以上 1200 延长段（立柱加长到 `高度+1200`、该段无踏步、护笼补环且最顶环环顶与立柱顶齐平）、构件布局（立柱位置与截面、横担长度与外伸 10、角钢竖肢背靠背贴立柱、角钢长度到立柱前缘、100×100 贴墙板中心与角钢对齐）、护笼环吸附踏步（最近踏步 + 间距不超过最大值 + 环顶贴踏步底面）、11 点路径关键点（起终点＝立柱几何中心、t 内 60、n 向墙 105、半宽 355、弯起点 630、圆头顶点 985）、两段 90° 圆头半径、路径弧长、11 根竖杆的外圈均布与对称、环扫掠截面 50×5 与竖杆 30×5、最顶「倒 L + 顶环」9 点路径（8 段＝6 直线 + 2 圆弧，逐点校验 n/t/h、圆头顶点 985、倒 L 竖段 n=−700 对齐 t=±355）。全部通过时输出 `wall_ladder geometry self-test: OK`。

这是一份**几何建模**插件。若需要注册为带 Class / Tag / 规格属性的 OpenPlant 智能组件，还需结合项目使用的 OPM 类库、EC Schema 和目录规范。
