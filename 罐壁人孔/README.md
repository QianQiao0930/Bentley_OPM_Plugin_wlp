# Bentley OpenPlant Modeler 罐壁人孔 Python 插件

`tank_wall_manhole.py` 在 Bentley OpenPlant Modeler（基于 MicroStation 的 Python 环境）的活动三维模型中交互放置**罐壁（筒体）人孔**：水平轴线的筒节 + 带螺栓孔的法兰 + 盲盖板 + 盖板把手，并可选装盖板的**铰链（hinge）**或**吊杆（davit）**。

尺寸依据图 **BN-DS-A 4《DAVIT FOR MANWAY COVERS》（Sheet 1 of 2）**。吊杆直径按图纸表格由"人孔公称尺寸 + 法兰压力等级"查得；吊杆/铰链的销孔、开口销、吊环螺栓、盖板把手等尺寸也取自该图。

> 该图纸是**人孔盖吊杆**的细节图（第 1 张，共 2 张），本身没有给出人孔法兰本体的尺寸。插件里人孔本体的筒节/法兰/盖板/螺栓尺寸是一组**参考默认值**（见下表），正式建模前应按项目采用的人孔标准（人孔规格书或 ASME B16.5）在代码常量中改成实际值。

## 吊杆单独测试脚本 `davit_only.py`

`davit_only.py` 是**只画吊杆**的独立脚本（不含人孔法兰、盖板、螺栓、把手），用于先单独验证吊杆形状；它不导入也不改动 `tank_wall_manhole.py`。运行方式与其它脚本相同：Python Editor 里执行 → 面板填参数 → 模型里点取放置点（点取点是**扁钢腰形孔中心，即 M20 螺栓轴线**）→ 预览 / 确定。

按图纸放的吊杆形状：

| 部位 | 做法 |
| --- | --- |
| 立柱 / 回转段 | **实心圆钢 ØD**（默认 45，即 24" + ASA 150 lbs），穿过法兰上的一对吊耳环 |
| 弯头 | 圆钢经 **R220** 弯头由竖直折成水平（真圆弧，不是折线） |
| 水平臂 | 圆钢 ØD，在**盖板顶边之上 140**（= 法兰半径 + 140）水平伸向盖板顶部 |
| **臂最末端（扁头）** | **100 宽 × 120 长 × D/2 厚** 的水平矩形板，**孔开在扁头正中心**，裁 **40 × 22 长圆孔**（两条长边为直线、两端半圆，用一个独立的长圆孔刀具体一次裁穿） |
| **圆管↔扁头过渡** | **放样（直纹过渡）**：两个断面点数与起点一一对应（矩形端 24 点、**含 4 个精确角点**，因此与扁头端面严格对齐、角上不留缺口；圆端取同序号的 ØD/2 圆周点），放样长度 = **1.5 D** |
| **盖板顶部连接** | **盖板（盲法兰）边缘**焊**两只吊耳**（只焊在盖板上，不跨到人孔法兰）→ 中间穿 **Ø16 全螺纹螺柱**（两端各 1 个螺母，取代原来的插销）→ 一根**竖向 M20 调节吊环螺栓**（吊环套住螺柱、杆穿过扁头的 40×22 长圆孔）→ **2 个螺母 + 垫圈**压紧在扁头上；拧螺母即可调节扁头高度 |
| 法兰回转吊耳 | 两只，销孔 = **D + 3**（图中 "D"+3），立柱下端伸出后用 **Ø5 开口销**（图中 5mm DIA FOR COTTER PIN）防脱 |

> 扁头厚、放样长由 D 自动推导（`FLAT_HEAD_HEIGHT_FACTOR = 0.5`、`LOFT_LENGTH_FACTOR = 1.5`），面板里只需给 D、扁头宽、扁头长。长圆孔 40 × 22（长沿臂轴线）恒定，可改 `SLOT_LENGTH` / `SLOT_WIDTH`。**点取点即扁头正中心**，扁头沿臂轴线前后各半长（120 长时即 −60…+60）。
>
> M20 调节吊环螺栓的做法与参数照同目录的 `eye_bolt_only.py`：孔心为原点、孔轴为局部 Y（正好是水平销方向），圆环中心线半径 = 孔半径 + 圆钢半径 = 25，颈弯 R30 与圆环外切，杆顶到孔心 200、螺纹段 100 MIN。
>
> 盖板把手为**两个 Ø20 卷钩把手**，各距竖直中心线 175（图中 "175 | 175"），位于盖板中心高度；把手平面**垂直于盖板法兰**（含人孔轴线与竖直方向）：从盖板外面垂直伸出 60 → 90° 下弯 → 竖直段 → 下端 180° 卷钩收回盖板一侧，左右镜像。
>
> 放样按三级依次尝试，面板信息行会显示实际用的哪一种：
> 1. **直纹放样**（`DgnRuledSweepDetail` + `ISolidPrimitive.CreateDgnRuledSweep`）；
> 2. **`SolidUtil.Create.BodyFromLoft`**（有些版本才有）；
> 3. **台阶近似**：把 67.5 长的放样切成 24 片、逐片用同一组角度采样的小棱柱，尽量并成一个实体，并失败就分开写入。外表面是分段的，但**保证圆管与扁头之间一定连上、不会断开**。
>
> 若面板显示用了台阶近似，说明该 OPM 版本的直纹放样内核调用没成功；具体原因（构造 / Create / ToElement 哪一步、返回什么）会同时写进 `davit_only_debug_log.txt`，把它发我就能把真正的放样打开。若想强制看台阶效果，把 `_add_loft` 里第 1、2 步注释掉即可。

面板参数：吊杆直径 D、立柱偏距（腰形孔中心到立柱轴线的水平距离，须 > 2×R220 且留够放样 + 扁头）、上吊耳环标高、扁头宽 / 长、朝向、是否生成吊耳环、反向。吊耳环与立柱下端由"上吊耳环标高"自动推导（下环在其下 144，立柱下端再低 25），因此两环始终落在立柱上。

不开 OPM 也能先验算尺寸（只跑布局与参数校验，不生成图元）：

```
python -B davit_only.py --self-test
```

全部通过时输出 `ALL LAYOUT CHECKS PASSED`。

## 使用方法（选型 → 点取 → 预览 → 确定）

1. 在 OpenPlant Modeler 中打开或新建一个**三维**、公制的 DGN 模型。
2. 打开 **Utilities（实用工具）→ Python** 的 Python Editor。
3. 新建 Python Project，选择或复制 `tank_wall_manhole.py`，然后执行。
4. 在弹出的面板里选择：
   - **公称尺寸**：18" / 20" / 24"；
   - **压力等级**：ASA 150 / 300 / 600 lbs（与公称尺寸一起决定吊杆直径 D）；
   - **连接形式**：吊杆 davit / 铰链 hinge；
   - **朝向**：人孔轴线在平面内的方向，0° 沿模型 +X，逆时针为正；
   - **筒节长度**：罐壁外表面到法兰背面；
   - **反向**：人孔轴线转 180°；
   - **生成法兰螺栓与螺母**、**生成铰链 / 吊杆**：两个开关，默认全开。
5. 在模型中点取**罐壁外表面上的人孔中心点**，立即生成一版预览。
6. 看着预览调整面板选项，**改一次就自动重建一版**（旧的预览会被删掉，模型里始终只有一版）；想换位置直接再点一次。
7. 觉得对了就点**【确定】**：当前这版预览就地保留，工具结束。
   点**【取消】**（或右键、直接关掉面板）则删除预览、放弃本次生成。

整组人孔（筒节 + 法兰 + 盖板 + 螺栓 + 把手 + 吊耳 + 铰链/吊杆）写成一个名为 `TANK_WALL_MANHOLE` 的**普通单元（Normal Cell）**，因此可以整体选中、移动、复制或删除。

脚本按活动模型的 `MASTER_UNITS_PER_METRE` 换算，输入始终按 mm 解释，不要求主单位设成 mm。

## 几何规则（局部坐标）

以点取点为原点建立局部坐标系：**x 沿人孔轴线（由罐壁向外）、y 水平切向、z 竖直向上**。

| 项目 | 规则 |
| --- | --- |
| 筒节 | 空心圆柱，x = 0 → 筒节长度；外径 / 内径取表值 |
| 法兰 | 圆盘，x = 筒节长度 → +法兰厚；掏中心通径与 n 个螺栓孔 |
| 盖板 | 圆盘，x = 法兰前面 + 垫片 2 → +盖板厚；掏同样的螺栓孔 |
| 螺栓 | 每颗 = 六角头（法兰背面）+ 杆 + 垫圈 + 螺母（盖板前面），沿螺栓圆均布、起点错开半个节距 |
| 把手 | Ø20 圆钢水平 U 形，腿距 300、伸出盖板外面 100、握杆 150、弯头 R75，位于盖板中心高度 |
| 法兰吊耳 | 每只由两块水平板组成：内块落在法兰厚度内、径向压住法兰边缘；外块 50 宽、从法兰前面伸到销轴位置。两只吊耳中心位于 z = ±45 |
| 铰链 | 盖板吊耳夹在两只法兰吊耳之间，开 40×22 腰形孔；Ø16 竖直销轴自上而下穿过三块吊耳，下端用 Ø4 开口销防脱。盖板绕该竖直轴侧开 |
| 吊杆 | ØD 立柱穿过两只法兰吊耳（可绕自身轴线回转），下端用 Ø5 开口销防脱；立柱向上经 R220 弯头转到水平臂，再 90° 下弯（R60）垂直落到盖板中心线；端部开 Ø(D+3) 横孔 |
| 吊环螺栓 | 竖直穿过盖板吊耳（高度 160），配 2 个螺母 + 垫圈，尾部 Ø4 开口销；吊环内孔 R30 |
| 吊杆—吊环连接 | 一根沿人孔轴线的连接销同时穿过吊杆端部横孔与吊环，销端用 Ø5 开口销防脱 |

吊杆的水平臂高度取"盖板外缘 + 120"，因此吊杆始终从盖板上方跨过；吊杆平面相对吊环平面外移 30，使连接销能同时穿过两个孔。

## 实现说明

- **预览 / 确定机制**（与 `安保围栏/security_fence_body.py`、`安保围栏-门/security_fence_gate.py` 相同）：`_build_manhole_cell()` 在内存里把整组人孔建完（**不写模型**），成功后 `commit()` 才 `AddToModel()`；`replace_tank_wall_manhole()` 负责"先建新的一版、写进模型，再删掉上一版预览"。**新的一版构建失败时旧预览不会被删**。
- **单元封装**：`_ManholeCellBuilder` 先创建孤立单元头，逐个 `AddChildElement`，最后 `AddChildComplete`；任何一步失败就整体放弃，不会在模型里留下半成品。
- **空心件**：筒节、法兰、盖板都是外圆柱减内圆柱（及螺栓孔）；内圆柱两端各外伸 2 mm，避免端面共面导致布尔减法失败。
- **圆钢扫掠**：把手与吊杆都是圆形截面沿"直线—圆弧—直线…"复合路径扫掠成的 SmartSolid；路径曲线与截面只作为中间件，不写入单元。弯头是**真圆弧**（`DEllipse3d.FromPointsOnArc`），不是折线近似。
- **孔在构件内掏**：吊耳孔、腰形孔、开口销孔、横孔都在构件转成单元**之前**用布尔减法完成，因此写进单元的是最终实体。
- **腰形孔**：40×22 腰形孔用三个 Ø22 竖直圆柱（中间 1 个 + 两端各偏 9）近似，总长 9 + 22 + 9 = 40、宽 22，与图纸一致。
- **单位换算**：所有尺寸以 mm 计算，统一乘 `UOR/米 ÷ 1000`，因此英尺或其它主单位模型也能用。
- **参数校验**：公称尺寸只接受 18/20/24，压力等级只接受 150/300/600，连接形式只接受 hinge/davit，朝向必须是有限数字，筒节长度必须为正；校验不通过时保留上一版预览并在面板报错。
- **选项防抖**：输入框每敲一个字符都会触发重建请求，`REGENERATE_DELAY_MS`（150 ms）内只执行最后一次。
- **排错**：生成期间若 Bentley 几何内核报错，会在本目录写入 `tank_wall_manhole_debug_log.txt`。

## 已知限制

- 只建模**关闭状态**的人孔盖，不生成开启角度；铰链与吊杆都是**静态表示**，不是可运动机构。盖板顶部的法兰吊耳做成 L 形：竖腿落在法兰厚度内形成焊接，盖板顶边之上的水平段前伸到销轴位置，因此不会与盖板本体相碰。
- 只做**罐壁（水平轴线）人孔**，不支持罐顶（竖直轴线）人孔。
- 吊杆按图纸做成"立柱 + R220 弯臂 + 端部横孔 + 连接销"的固定形状；吊杆回转范围、吊装轨迹、载荷计算不在本插件范围。
- 不生成焊缝、垫片实体、衬管（0.5" pipe）、黄铜垫环、涂装，也不附材质 / Class / Tag 属性。
- 图纸上的 175 + 175 双孔布置未还原（端部按单孔单销处理）。
- 法兰螺栓数量固定按表值均布，不支持自定义角度或跳开某几颗。

## 调用方式

- 界面入口：`PyMain()`（脚本末尾有 `if __name__ == "__main__"`，在 Python Editor 中直接运行即可）。
- 编程调用：
  - `draw_tank_wall_manhole(placement_point, options=None)`：直接生成并写入模型，返回统计字典；
  - `replace_tank_wall_manhole(placement_point, options, previous_handle)`：预览用的重建接口，返回 `(新单元句柄, 统计字典, 是否删掉旧预览)`；
  - `_build_manhole_cell(placement_point, options)`：只构建不写模型，返回 `(builder, 统计字典)`。
- `options` 为字典，缺省键取默认值：

  | 键 | 取值 | 默认 |
  | --- | --- | --- |
  | `nominal_size` | `18` / `20` / `24` | `20` |
  | `rating` | `150` / `300` / `600` | `150` |
  | `mode` | `"davit"` / `"hinge"` | `"davit"` |
  | `heading_deg` | 朝向（度），0° 沿 +X | `0.0` |
  | `neck_length` | 筒节长度（mm） | `150.0` |
  | `mirrored` | 轴线转 180° | `False` |
  | `include_bolts` | 生成法兰螺栓 | `True` |
  | `include_lifting` | 生成铰链 / 吊杆 | `True` |

## 几何自检

`_geometry_selftest.py` 用桩件模拟 MSPy API，**不需要 MicroStation**，任何 Python 3（Tk 可用）都能跑：

```
python _geometry_selftest.py
```

覆盖吊杆直径表、选项校验、各站位与半径、螺栓圆均布、圆弧中点、铰链销轴与 40×22 长圆孔、
单位换算（1 mm = 12 UOR 的主单位）、反向与选项开关等共 30 项，全部通过时输出
`ALL CHECKS PASSED`。改完 `tank_wall_manhole.py` 后建议重跑一遍。

**吊杆模式的自检目前会打印一行 `[SKIP]`**：吊杆支撑件用到了 MicroStation 的
`SolidUtil.GetBodyEdges` / `BlendEdges` 等内核棱、顶点拓扑查询，纯 Python 桩件无法
重建这些拓扑，因此吊杆模式的几何检查在桩件下跳过（不假装通过），需在 OPM 中实机验证；
其余检查照常执行。

这是一份**几何建模**插件，创建的是活动 OPM 模型中的 MicroStation SmartSolid 图元。若需要把它注册为带 Class / Tag / 规格属性的 OpenPlant 智能组件，还需结合项目使用的 OPM 类库、EC Schema 和目录规范。
