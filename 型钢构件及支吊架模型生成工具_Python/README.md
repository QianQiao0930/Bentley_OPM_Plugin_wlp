# 型钢构件及支吊架模型生成工具 — Python 版

为 Bentley OpenPlant Modeler（OPM）/ MicroStation 的 MSPython 环境提供建模与查询脚本。

本目录是 Python 版的工作根目录。各功能目录与 `bentley_ui`、`型钢截面生成器`、`管道信息查询` 必须保持同级；入口脚本中的 `REPO_ROOT` 指向本目录，不要求它是 Git 根目录。

- [仓库总入口](../README.md)
- [Python 分发打包说明](分发打包说明.md)
- [独立 C# 版](../型钢构件及支吊架模型生成工具_CS/README.md)

这些脚本多数生成活动模型中的 SmartSolid 几何；`管道信息查询` 为只读工具。需要带 Class / Tag / 规格的 OpenPlant 智能组件时，仍须结合项目类库、EC Schema 和目录规范。

## 环境要求

- Bentley OpenPlant Modeler（基于 MicroStation）
- Power Platform Python 环境（MSPy 模块）——仅 Python 插件需要
- 三维、公制 DGN 模型

## 通用使用方法

1. 在 OPM 中打开或新建一个**三维**、公制的 DGN 模型。
2. 打开 **Utilities（实用工具）→ Python** 的 Python Editor。
3. 新建 Python Project，选择或复制对应目录中的脚本，然后执行。
4. 在弹出窗口中设置参数，确认后在模型内点取放置点；右键可取消。
5. 每个脚本的**具体参数与几何规则**见各自目录下的 `README.md`。

> 注意：脚本按当前 DGN 的 `MASTER_UNITS_PER_METRE` 换算单位，因此输入尺寸统一按 mm 解释，不要求把主单位设成 mm。

## 与 C# 版的关系

两个版本分别维护，C# 运行时不启动本目录中的 Python。两侧共用 DGN 中的 `PipeSupportComponents` ItemType 数据契约；修改属性字段或统计口径时，需要同步核对两个版本。

C# 工程内的 `Development`、`Deployment` 中也有 Python 工具，属于 C# 开发和部署流程，保留在 C# 工程内。

## 迁移后使用

2026-11-01 起，Python 入口位于本目录下。OPM Python Project、快捷方式或手工配置若记录了旧入口的绝对路径，需要重新指向这里；仓库外的配置未自动改写。

打包命令从本目录执行。详细步骤见 [分发打包说明](分发打包说明.md)。

## 排错

部分脚本会在各自目录写入 `*_debug_log.txt`。本次目录整理没有修改 Python 业务代码；离线检查无法替代 OPM 中的实际放置验证。
