# 盘梯建模

平台规则修正：中间休息平台与顶部平台的板顶面，统一位于平台段梯梁下缘基准Z+200mm，与梯梁顶部平齐；板厚4mm全部向下，平台只生成一块平板，不含上下折边。平台辅助线同步改为真实顶面标高。platform_specs标高仍表示梁下缘基准，避免把整个连续梯梁路径一起抬升。普通踏板的前下折/后上折保留。顶部回折横梁开口方向按平台末端向外的方向确定，不按罐径向选侧；正反旋向均覆盖回归测试。

当前折板与顶部回折规则：踏板及中间休息平台均为前长边（朝下一级、靠近上楼者）下折40mm，后长边（朝上一级）上折40mm；径向两侧不折。水平板厚4mm，从顶面辅助线向下。顶部平台仅保留前长边下折，不生成后长边上折。中间/顶部平台实体已经接入“生成U形梯梁与Z形踏板”按钮。平台平面轮廓为连接内外两根直线平台路径的四边形，与现有水平直线路径匹配。

顶部外侧梯梁及上移200mm后的外侧栏杆辅助线，末端均增加水平向内的700mm回折段（实际取内外路径间距），连接各自内侧路径末端。外梁回折段也生成U形实体，转角使用共享竖直斜接截面，回折段截面横向垂直于回折直线，避免仍沿径向布置造成退化。保持腹板底部外角基准及Z方向向上200mm；转角处斜接宽度会增加。仍需OPM检查转角实体与相邻梁的安装节点。


当前截面规则更新：内梁下缘路径半径=罐外半径+100mm腿宽+输入罐壁间隙（20m罐、间隙0时为10100mm），外路径半径再加700mm净宽，为10800mm。每步转角同步按250/10100计算。截面基准改为腹板底部外角，全部200mm高度位于路径上方；内外梁仍背靠背。旧中心基准说明仅为历史记录。日志不再print到系统控制台；运行时尝试隐藏同进程明确命名的Python控制台，只保留插件日志窗口和日志文件。平台直线的弦向内偏移仍需复核。

## 竖直U形梯梁生成（2026-10-06）

新增“生成竖直U形梯梁并点取罐中心”按钮；原“绘制辅助线”按钮继续仅绘线。新按钮只恢复内外两条梯梁，栏杆、踏步实体、平台实体及三角支撑不生成。

截面固定为200mm高×100mm腿宽×6mm厚。路径基准是腹板外侧面的几何中心，因此上下缘是路径Z±100mm。每个截面高度沿世界Z，宽度沿罐径向；内梁开口朝罐中心，外梁开口朝罐外，两腹板背靠背。基准位于外表面，不是板厚中面。

使用明确定向的截面逐段封闭放样，包含梯段及平台水平连接段，不采用默认垂直于三维切线的扫掠。每侧组装为一个普通单元，内部是相邻共享截面的分段实体，尚未布尔合并为单一实体。路径仍是采样近似；普通手动扫掠不会因本次新增按钮自动获得定向约束。需要使用新按钮生成。

内梁腿朝罐壁，0mm间隙时将与罐体重叠；生成日志会提示，需结合直线平台弦向内偏移量确认实际间隙。截面中心基准也意味着梁顶高于原踏步顶面100mm，需另行确认踏步安装标高或调整梁基准标高。本次优先严格执行外侧面中心基准。

截面定向、200/100/6尺寸、基准点、背靠背、正反旋向及原入口回归检查通过。Bentley实体放样与连接节点仍需OPM实际运行验证。


## 当前入口：仅绘制放样辅助线（2026-10-06）

执行 `spiral_stair.py`，点击“绘制辅助线并点取罐中心”。当前仅绘制各梯段的内外螺旋基准线、每个踏步顶面闭合轮廓、休息/顶部平台顶面边界和罐中心轴。默认共107条线；5m平台间隔时共113条线。辅助线封装为一个 `SPIRAL_STAIR_GUIDES` 普通单元，保留点取放置、单位换算及日志功能。

实体与栏杆生成已从当前入口隔离到 `solid_model_isolated.py`，当前不加载栏杆插件、不创建U形实体、不进行实体扫掠。盘梯平台三角支撑的布局与建模代码已删除，不涉及独立管道支吊架插件。辅助线只表达输入几何，不能视为实体净宽或干涉检查通过。

以下实体说明记录之前版本，当前入口不执行。


入口：`spiral_stair.py`。在 Bentley OPM 的 Python Editor 执行，输入参数，点击“生成并点取罐中心”，然后在三维模型中点取罐中心基准点。右键取消。输入长度统一 mm，起始角使用 rad；标高相对于所点基准点，罐体本身不生成。

必须保留同级 `普通钢结构围栏/steel_handrail.py`，盘梯直接调用其 `build_continuous_handrail` 接口，盘梯代码没有自行创建栏杆立柱、扶手或中横杆。整个外缘路径含第一梯段、休息平台、第二梯段和顶部平台，一次建栏杆并统一分配立柱，避免各段分别创建端柱。1050 mm 高度按连接球最高点定义。原有围栏入口的默认参数不变。

默认参数按给定规则：罐外径20000、起终标高0/20000、休息平台高度间隔10000、踏步高200、内缘踏面250、径向宽700、贴罐间隙0、U形200×80×6、板厚4、栏杆1050。默认两梯段各50步，每步0.025 rad，梯段合计2.5 rad，倾角38.6598°。平台按从起点标高向上每隔指定高度自动生成，顶部不会再重复创建休息平台。

规则未指定的平台采用内缘长1000 mm的局部扇形，可修改；默认每个平台增加0.1 rad，每个休息平台出口决定下一梯段起始角。顶部平台为局部操作平台，未创建罐顶。平台支撑使用暂定φ50实体斜撑，每个平台两根，罐壁连接点低于平台800 mm，需按项目结构设计确认。

几何路径使用弦高误差不超过0.5 mm的采样，U形截面保持径向/竖向，用连续截面放样形成螺旋扫掠近似；踏步与平台为水平扇形板。格栅暂以4 mm实体板表达，不包含格栅孔或防滑纹，因此不是加工级格栅模型。所有子件在内存创建完成后以一个普通单元写入模型，失败不会留下部分模型。

## 检查结果与适用范围

纯几何自检通过：踏步数、角度、坡度、顶面水平、标高、顺/逆时针轮廓方向、无效参数拒绝。运行 `_geometry_selftest.py` 可复核。

不能将默认模型声明为“所有检查通过”：700 mm 是两腹板基准半径差，内侧U形腿朝外时局部结构净宽保守值为700−80=620 mm，低于650 mm。若将U形腿反向，又可能与零间隙罐壁冲突。需按项目节点调整截面、罐壁间隙或增大径向宽度；当前保留输入规则，同时明确标记 `structural_width_pass=False`。例如径向宽度780时该保守值为700，但外半径相应变为10.78 m。

Bentley内需复核：U形上翼缘与各踏步接触、平台接口、支撑碰撞、栏杆顶装底板与梯边梁的安装节点、栏杆接缝以及顶部平台与实际罐顶连接。空间栏杆为细分直管近似，折点不使用原插件的水平R140圆角。当前不执行实体碰撞布尔检查，不能自动证明没有干涉。

本机仅完成独立几何测试和Python语法检查；尚未在OPM/MSPy宿主中验证实体API及最终实体拓扑。生成的是几何普通单元，不是带OpenPlant类别/材料属性的智能组件。

## 多休息平台与日志

界面“休息平台高度间隔”单位mm，默认10000；设为5000时，0→20000生成5/10/15m三个休息平台、四个25步梯段及一个顶部平台。间隔相对于起点标高计算，末段可短于该间隔；间隔大于总高度时只有一个梯段和顶部平台。每个实际梯段高度必须是踏步高度的整数倍，程序不会悄悄修改踏步高度。旧代码调用中的 `landing_z` 仍兼容：明确指定时采用单个固定标高平台；新界面使用 `landing_interval`。

点击生成后弹出“进度与错误日志”窗口，在等待点位、参数计算、每个踏步/平台、每段内外侧板、每根支撑、栏杆横杆/立柱/踢脚板、单元写入阶段记录开始和完成。失败保留最内层出错阶段及完整Python堆栈；例如“梯段3 外侧板放样”。窗口关闭后文件日志继续记录。

每次运行即时写入独立UTF-8日志：插件目录 `logs/spiral_日期时间_进程号.log`；目录不可写时使用系统临时目录，实际路径会显示在日志第一行。失败后可将该文件中的ERROR及堆栈发回定位问题。生成过程中禁用再次生成按钮，成功、失败或右键取消后恢复。

修复了连续栏杆中的tuple坐标误用：局部坐标不能传给要求DPoint3d `.x/.y/.z` 的距离函数。`_integration_selftest.py` 通过调用真实栏杆入口并替代Bentley实体API验证该回归、栏杆全局参数在异常后恢复，以及阶段日志和堆栈落盘。该测试不等同于OPM宿主实体生成验证。

空间踢脚板修复：按相邻水平法向的角平分线计算共享偏移顶点，保留各顶点Z，消除原逐段平移导致的接缝。仅连续空间栏杆接口启用。回归测试覆盖罐壁间隙150mm、5m/10m平台间隔和正反方向，并验证偏移距离及端点连续性。日志文件增加UTF-8 BOM，窗口支持复制完整日志与打开文件；Bentley控制台仍可能受宿主字符编码影响，建议从日志窗口复制或发送原始log文件。

放置事件修复：使用项目已有的Bentley/Tk交替消息循环，调用PythonMainLoop处理模型点击；参数窗口保留放置工具强引用，工具退出时一次性清理。日志新增工具安装、激活及点取坐标事件。重新运行前请关闭旧参数窗口，停止旧脚本，避免旧Tk主循环继续阻塞输入。

针对OPM返回的空间踢脚板BodyFromSweep eERROR，连续空间栏杆现采用共享斜接截面的逐段封闭实体放样，不再调用142段长路径扫掠。每段日志显示放样序号，失败指出段号；相邻段复用同一截面，130×6截面尺寸按斜接计算。普通栏杆仍使用原扫掠。新回归测试验证实际入口使用分段放样API及失败定位；仍须OPM宿主验证最终实体。

完整梯梁辅助路径：当前内外侧各生成一根独立连续三维线串，依次连接所有梯段与各平台入口/出口的水平直线；顶部平台也包含在路径中。两根梯梁线可独立选取，踏步和平台轮廓仍封装为辅助线单元。默认105条辅助线，5m平台间隔时107条。梯段仍为采样折线近似，尚未替换为Bentley原生光滑螺旋曲线；连接处仅保证端点连续，不保证切向光滑或实体扫掠成功。平台直线是端点连弦，平台边界轮廓仍为局部扇形；贴罐间隙为0时内侧弦可能进入罐壁范围，后续实体设计须确认间隙或平台形状。

简化Z形踏板：踏板轮廓视为顶面，水平板向下4mm；按径向内缘向上40mm、径向外缘向下40mm创建4mm宽竖边，以三个接触实体表达尖角折板，不模拟折弯圆角，也不布尔合并。使用生成U形梯梁与Z形踏板按钮；平台实体仍不生成。内外完整梯梁辅助线各向上复制200mm，作为独立可选取的内外栏杆路径，包括平台直线连接段。栏杆实体仍不生成。辅助线默认107条，5m平台间隔时109条。实体API仍须OPM验证。
