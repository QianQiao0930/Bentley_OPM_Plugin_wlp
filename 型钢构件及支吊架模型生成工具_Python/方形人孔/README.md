# Bentley OpenPlant Modeler 方形人孔 Python 插件

`SquareManhole.py` 可在 Bentley OpenPlant Modeler（基于 MicroStation 的 Python 环境）中绘制带盖的方形人孔。

## 几何规则

默认输入筒体 `600×600×100`、盖板 `620×620×40`、壁厚 `4` 后，几何如下（单位均为 mm）：

| 部件 | 尺寸与位置 |
| --- | --- |
| 筒体净空 | 600 × 600 × 100（可改为例如 500 × 500 × 150） |
| 筒体外形 | 608 × 608 × 100；壁厚 4；上下开口 |
| 盖板外形 | 620 × 620 × 40（可自定义）；壁厚 4；底面开口 |
| 装配间隙 | 盖板内侧 612 × 612，和筒体外侧之间每边 2 |
| 组合总高 | 104（筒体 100 + 盖板顶面 4） |
| 把手 | 2 件 Ø16 实心钢管；中心线长 140、高 60、弯曲 R32；沿盖板 Y 轴相对中心 +150 / −150 |
| 筒体把手 | 2 件 Ø16 实心钢管；水平装在筒体相对两外壁，中心线距筒体底面 50；主握杆平行 X 轴，向外伸出 60 |

盖板从筒体顶面向下套入 36 mm，因此“40 mm 高的盖子”在空间上不会使组合高度增加 40 mm，而只增加其上表面的 4 mm。

## 使用方法

1. 在 OpenPlant Modeler 中打开或新建 **三维**、公制的 DGN 模型。
2. 打开 **Utilities（实用工具）→ Python** 的 Python Editor。
3. 新建 Python Project，选择或复制 `SquareManhole.py`，然后执行。
4. 在弹窗中分别输入筒体的净长、净宽、高度，盖板的外形长、外形宽、外形高，以及壁厚。例如筒体填 `500`、`500`、`150`，盖板填 `520`、`520`、`40`。
5. 确认后，在图面中单击放置点；右键可取消。

图面点选的放置点是**筒体下口中心**，支持捕捉。脚本按活动模型的 UOR/米换算，因此输入始终按 mm 解释，不要求把主单位设成 mm。

## 实现说明

筒体由四个相连的 4 mm 壁在内存中创建后执行实体并集，最终是一个 SmartSolid；盖板的四个壁和 4 mm 顶板同样相并为另一个独立 SmartSolid。这与“立方体抽壳、删除面”的最终实体结果一致，且盖板与筒体仍可分别移动和编辑。

两个把手由圆形 Ø16 截面沿“直线—R32 圆弧—直线—R32 圆弧—直线”的倒 U 形路径扫掠为 SmartSolid，路径和截面不作为可见辅助图元保留。

筒体把手采用同一截面与路径尺寸，但路径转到水平面，两个端面贴合在筒体相对外壁，中心线标高为 50 mm；因此握杆平行盖板，向外突出 60 mm。

这是一份**几何建模**插件，创建的是活动 OPM 模型中的 MicroStation SmartSolid 图元。若需要把它注册为带 Class/Tag/规格属性的 OpenPlant 智能组件，则还需知道你项目使用的 OPM 类库、EC Schema 和目录规范。
