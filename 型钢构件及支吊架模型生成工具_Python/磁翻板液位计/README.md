# 磁翻板液位计

在 OPM 的 Power Platform Python 编辑器中运行 `magnetic_level_gauge.py`。
依赖 MSPy、PyQt5、win32gui，与项目中实体管口工具使用相同的 UI 集成方式。

1. 打开三维 DGN 模型，运行脚本。
2. 输入上下接口中心距 **L1**，单位 mm，范围 350～6000，默认 1400。
3. 可设置绕全局 Z 轴的旋转角。0° 时接管朝 −X，显示面朝 −Y。
4. 点击“开始放置”，点取**下接口标高处的筒体轴心**。可连续放置，右键结束。
5. 修改参数后再次点击“开始放置”才应用到下一次放置；已有模型不随 UI 更新。

点击“取消”与关闭窗口等效：先退出放置工具，等待原生清理完成后结束窗口循环。
界面为新拟态（Neumorphism）风格，浅灰白底、柔性双向阴影；每条输入参数各自
成框（凹陷输入槽），框内右侧自带加减钮，支持点按与按住连续步进，步长为该
参数设定的单步值；「开始放置」「取消」为浅凸胶囊按钮，按下转为凹陷。
窗口无系统边框、四角为圆角，标题栏自绘：按住标题栏空白处可拖动窗口，
右端是自绘的最小化与关闭钮（关闭与“取消”等效）。Alt+F4 仍可用。
首次打开时在 OPM 主窗口居中，之后记住关闭时的位置；保存的位置超出当前
屏幕时自动纠正。位置通过当前用户的 QSettings 保存，不写入 DGN。

每台仪表为一个普通单元，可整体选择、移动、旋转和删除。采用精确 RGB
设置红白翻片、浅灰筒体及深色手轮；建议用平滑/着色显示模式查看。

模型包括 Ø60 筒体、上下端盖法兰及螺栓、同侧两组接管和简化截止阀、
环形手轮、显示框、红白翻片、无数字刻度、安装卡箍和底部排污阀。
L1 仅改变接口间距及显示长度，其余构件维持展示尺寸。
筒体和端部接管为实心外观简化；不建内部浮子、通孔、螺纹。
红白分界固定在 50% 量程，不表示实时液位。

尺寸参考用户安装图的结构关系，非制造尺寸，也未注册为 OpenPlant 智能组件。
输入尺寸通过当前模型的 `GetUorPerMeter()` 换算，不要求主单位必须为 mm。
所有子构件创建成功后才整台写入模型，单元名称包含 L1。

本地可以检查 Python 语法和几何参数；实际 MSPy 图元生成、颜色显示和鼠标
交互仍需在安装 OPM 的环境中验证。
