# 竖直弯头的竖直耳轴（F2 · OPM Python）

> 本工具已迁移至 [`管道支吊架/F2-[竖直弯头的竖直耳轴].py`](../管道支吊架/F2-[竖直弯头的竖直耳轴].py)。当前文件夹仅保留旧版调试资料；请从新位置运行。

用于 Bentley OpenPlant Modeler / MicroStation 三维模型的参数化竖直弯头耳轴生成脚本。第一版通过选择已有 OpenPlant 弯头进行放置。

## 使用方法

1. 在 OPM 中打开一个三维 DGN 模型。
2. 从 Python Editor 运行 `管道支吊架/F2-[竖直弯头的竖直耳轴].py`。
3. 在界面中选择 A 型方底板、B 型圆底板或 C 型无底板、材料代码、可选耳轴壁厚，以及空心/实心耳轴。
4. 在模型中点取一个已有的 OpenPlant 90° 竖直弯头。
5. 点选合法弯头后自动进入拉伸与 AccuDraw 精确绘图状态。移动光标沿模型竖直方向预览耳轴轮廓与实时高度 H；左键确认后生成耳轴和底板。拉伸阶段右键取消并重新选择弯头；选取阶段右键退出。

界面使用仓库共用的 `bentley_ui` 组件，与管道支吊架工具保持相同的标题、卡片、字段、状态提示、生成记录和按钮风格。上次确认的高度、底板类型、空心/实心选择以及窗口位置会自动记忆。普通鼠标拉伸按光标在视图中沿世界竖直轴的投影确定高度；捕捉到图元或使用 AccuDraw 精确输入时，按调整后的 Z 标高确定高度，水平方向仍固定在耳轴轴线上。请在侧视图或轴测视图中拉伸，俯视图无法显示普通鼠标的竖直高度。

脚本从弯头 EC 实例读取公称直径、外径、90° 两端中心距和 `TRANSFORMATION_MATRIX`，自动判断一端水平、一端竖直，并计算两个端口中心和水平入弯方向。H 定义为所选弯头水平端中心线到新构件最低点的竖向距离：A/B 型有底板时终点为底板下表面（勾选 F 时为覆面下表面），C 型无底板时终点为耳轴钢管底端。参考表未覆盖的主弯头 DN 不做未经确认的插值。

## F2 编号与附加项

编号格式：`F2-主管 NPS-耳轴 NPS(非默认壁厚)-材料代码-H-底板类型[-F]`。例如 `F2-16"-8"-C1-500-A`；用户指定不同于默认 STD 的壁厚 22.23 mm 时写作 `F2-16"-8"(22.23)-C1-500-A`。H 按毫米四舍五入到整数。材料代码由用户选择，须与主管材料相同或相容。

`F` 仅用于 A/B 底板与 PTFE 滑板组合的情况。勾选后会在底板下生成一块同尺寸的 **3 mm 镜面不锈钢覆面**，H 的终点改为覆面下表面。与外部支承面之间的 15/25 mm PTFE 安装间隙须在现场设计中预留，插件不生成未选定的支承面。图注中的 `UP` 表示耳轴朝上，`HE` 表示水平弯头；当前竖直弯头的向下耳轴均不标这两个附加项。非 90° 弯头尚不支持，故也不附加弯角说明。

模型写入一个整组单元，并附加 `PipeSupportComponents` 公共 ItemType，供管道支吊架统计和清单导出使用。

第一版只接受竖直端朝上的标准 90° 圆弧弯头。普通图元、非弯头、倾斜弯头、竖直端朝下的弯头及两端中心距不一致的弯头会给出提示，并允许重新选择。

## 几何实现

- 所选弯头不会被修改或重复生成。
- 插件按读取到的端口坐标重建一个圆环截面沿 90° 真圆弧扫掠的实心外包络，专门作为刀具体。
- 竖直耳轴延伸至弯头中心线，然后用弯头外包络执行布尔差集，从而得到与弯头外表面吻合的鞍口。
- 切削刀具体不会写入 DGN。
- 耳轴默认按 STD 壁厚空心钢管建模，也可在界面中指定壁厚或改为实心圆钢。
- 耳轴下部按图切出 Ø6 横向通气孔。

## 尺寸表说明

耳轴 DN 与 A 型底板尺寸按用户提供的表 1 编入脚本。B 型底板直径按图取“耳轴外径 + 25 mm”，厚度沿用表 1；C 型不生成底板。

脚本中的大口径壁厚仅用于可视化实体，并不替代项目管道等级或制造数据。正式出图前应按项目规范复核弯头壁厚、耳轴壁厚、焊缝和载荷计算。

## 输出与排错

正常情况下输出包含耳轴、底板及可选覆面的整组单元，并附加公共支吊架 ItemType。若 Bentley EC 查询或几何内核返回错误，会在 `管道支吊架/模块/日志/竖直弯头的竖直耳轴_debug_log.txt` 写入诊断信息。
