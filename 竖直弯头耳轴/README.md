# 竖直弯头耳轴（OPM Python）

用于 Bentley OpenPlant Modeler / MicroStation 三维模型的参数化竖直弯头耳轴生成脚本。

## 使用方法

1. 在 OPM 中打开一个三维 DGN 模型。
2. 从 Python Editor 运行 `竖直弯头耳轴.py`。
3. 在界面中选择弯头 DN、中心线弯曲半径和高度 H。
4. 可选择 A 型方底板、B 型圆底板或 C 型无底板，并设置水平管方向。
5. 单击“确定”，在模型中点取底板下表面中心。

脚本将按参考图表自动确定耳轴管径和底板尺寸。H 定义为底板上表面到水平管中心线的高度；C 型无底板时，H 从点取标高算起。界面只列出表 1 明确覆盖的主弯头 DN，未对 DN65、DN80、DN125 等缺项做未经确认的插值。

## 几何实现

- 弯头是圆环截面沿 90° 真圆弧扫掠形成的 SmartSolid，不是折线近似。
- 建模时先生成一个实心弯头外包络作为刀具体。
- 竖直耳轴延伸至弯头中心线，然后用弯头外包络执行布尔差集，从而得到与弯头外表面吻合的鞍口。
- “保留生成的空心弯头”开启时，另行用内外两次扫掠和布尔差集生成可见空心弯头；切削刀具体不会写入 DGN。
- 耳轴默认按 Sch40 空心钢管建模，也可在界面中改为实心圆钢。
- 耳轴下部按图切出 Ø6 横向通气孔。

## 尺寸表说明

耳轴 DN 与 A 型底板尺寸按用户提供的表 1 编入脚本。B 型底板直径按图取“耳轴外径 + 25 mm”，厚度沿用表 1；C 型不生成底板。

脚本中的大口径壁厚仅用于可视化实体，并不替代项目管道等级或制造数据。正式出图前应按项目规范复核弯头壁厚、耳轴壁厚、焊缝和载荷计算。

## 输出与排错

正常情况下输出独立的耳轴、底板和（可选）弯头 SmartSolid。若 Bentley 几何内核返回错误，会在本文件夹写入 `竖直弯头耳轴_debug_log.txt`。
