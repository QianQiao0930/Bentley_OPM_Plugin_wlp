# 竖直弯头耳轴（OPM Python）

用于 Bentley OpenPlant Modeler / MicroStation 三维模型的参数化竖直弯头耳轴生成脚本。第一版通过选择已有 OpenPlant 弯头进行放置。

## 使用方法

1. 在 OPM 中打开一个三维 DGN 模型。
2. 从 Python Editor 运行 `竖直弯头耳轴.py`。
3. 在界面中输入测试高度 H，并选择 A 型方底板、B 型圆底板或 C 型无底板。
4. 在模型中点取一个已有的 OpenPlant 90° 竖直弯头。
5. 插件读取弯头 EC 信息并自动生成耳轴和底板；所选弯头保持不变，可继续点选其他弯头，右键退出。

界面使用仓库共用的 `bentley_ui` 组件，与管道支吊架工具保持相同的标题、卡片、字段、状态提示、生成记录和按钮风格。高度、底板类型、空心/实心选择以及窗口位置会自动记忆。

脚本从弯头 EC 实例读取公称直径、外径、90° 两端中心距和 `TRANSFORMATION_MATRIX`，自动判断一端水平、一端竖直，并计算两个端口中心和水平入弯方向。H 定义为底板上表面到所选弯头水平端中心线的竖向距离；C 型无底板时，耳轴底端直接位于该反算标高。参考表未覆盖的主弯头 DN 不做未经确认的插值。

第一版只接受竖直端朝上的标准 90° 圆弧弯头。普通图元、非弯头、倾斜弯头、竖直端朝下的弯头及两端中心距不一致的弯头会给出提示，并允许重新选择。

## 几何实现

- 所选弯头不会被修改或重复生成。
- 插件按读取到的端口坐标重建一个圆环截面沿 90° 真圆弧扫掠的实心外包络，专门作为刀具体。
- 竖直耳轴延伸至弯头中心线，然后用弯头外包络执行布尔差集，从而得到与弯头外表面吻合的鞍口。
- 切削刀具体不会写入 DGN。
- 耳轴默认按 Sch40 空心钢管建模，也可在界面中改为实心圆钢。
- 耳轴下部按图切出 Ø6 横向通气孔。

## 尺寸表说明

耳轴 DN 与 A 型底板尺寸按用户提供的表 1 编入脚本。B 型底板直径按图取“耳轴外径 + 25 mm”，厚度沿用表 1；C 型不生成底板。

脚本中的大口径壁厚仅用于可视化实体，并不替代项目管道等级或制造数据。正式出图前应按项目规范复核弯头壁厚、耳轴壁厚、焊缝和载荷计算。

## 输出与排错

正常情况下只输出独立的耳轴和底板 SmartSolid。若 Bentley EC 查询或几何内核返回错误，会在本文件夹写入 `竖直弯头耳轴_debug_log.txt`。
