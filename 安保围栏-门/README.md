# Bentley OpenPlant Modeler 安保围栏大门 Python 插件

`security_fence_gate.py` 在 Bentley OpenPlant Modeler（基于 MicroStation 的 Python 环境）的活动三维模型中交互放置**安保围栏大门**：在工具设置面板里选单扇门 / 双扇门，然后在模型中点取门洞中心的地面点，整樘大门立即生成一版预览；改选项会自动重建，点【确定】保留。

整樘大门（门柱 + 门扇门框 + 斜撑 + 菱形网 + 防攀悬臂与刺钢丝 + 简化活页 + 混凝土基础）写成一个名为 `SECURITY_GATE` 的**普通单元（Normal Cell）**，因此可以整体选中、移动、复制或删除。

## 尺寸与规范

尺寸按 mm 解释，主要尺寸与 GS-M16《Specification for 1.83m Security Fence》的 **Double and Single Gates** 一节对应：

| 构件 | 尺寸与做法 |
| --- | --- |
| 门扇门框 | φ42.8 × 2 钢管，四角**45° 斜接** |
| 斜撑 | φ21.4 钢管，自合页面下角沿对角线升至中缝面上角 |
| 菱形网 | 网孔 64、网丝 φ2.5（与围栏同规格），裁剪在门框内 |
| 防攀悬臂 | **门扇为竖直段**：从 1800 直上 450，无弯头；**门柱仍为 45° 斜挑**（与围栏主体一致，R100 弯头） |
| 刺钢丝 | 3 道 φ2.5，沿悬臂按 1/3、2/3、3/3 布置；每 500 一对抗 φ1.2、长 28 的 V 形刺 |
| 活页（合页） | 每扇 3 个沿高度均布（1/4、1/2、3/4），简化为竖直销轴 φ16 × 90 + 上下两块连接板 40 × 6；连接门扇立柱与门柱（或预埋柱位置） |
| 门扇高度 | 顶部 1800（与围栏网片顶、悬臂起点齐平），下缘离地 50 |
| 门洞净宽 | 单扇 1200、双扇 4270（两扇各 2105），可在面板中改 |
| 门柱（可选） | φ100、壁厚 4、管长 2600（地上 1800 + 埋深 800），与围栏转角 / 拉紧柱同规格 |
| 混凝土基础（可选） | 400 × 400 × 600，顶面与地面齐平 |

## 与 GS-M16 规范的对应关系

| 规范要求 | 本脚本 | 说明 |
| --- | --- | --- |
| 门扇 φ42.8 × 2 钢管、四角斜接 | φ42.8、壁厚 2、45° 斜接 | 一致 |
| 斜撑 φ21.4 钢管 | 同 | 一致 |
| 菱形网覆盖门框 | 网孔 64、网丝 φ2.5 | 与围栏网片同规格 |
| 大门配与围栏一致的安全悬臂 | 门扇竖直 450、门柱 45° 斜挑、3 道刺钢丝 | 按项目要求门扇改竖直，门柱仍与围栏一致 |
| 单扇门 1.2 m、双扇门 4.270 m | 门洞净宽 1200 / 4270 | 除非另有规定，可在面板中改 |
| 转角 / 门 / 拉紧柱 φ100 × 2、高 2.6 m，埋入 400 × 400 × 600 B 级混凝土块 | φ100、壁厚 4、管长 2600，基础可选 | 管径一致；壁厚 4 mm 与围栏插件保持一致 |
| 合页 | 简化活页（竖直销轴 + 上下连接板） | 经验尺寸，非规范值；保证门扇与门柱有连接关系 |
| 蘑菇盖、底板、涂装、1.6 mm 绑线、拉紧螺栓、门锁 | 未建模 | 本插件只做门体几何 |

两点与安保围栏主体一致的处理：

- **壁厚**：门柱沿用围栏的 4 mm（规范写 2 mm）以保证空心管布尔运算稳定；门扇门框 / 斜撑按规范的 2 mm。需要严格照规范时改 `GATE_POST_WALL` / `GATE_FRAME_WALL` 即可。
- **门洞净宽**按**两门柱内表面之间**理解（规范只写了门宽）。门柱中心因此位于 ±(门洞净宽 / 2 + 50)。

## 使用方法（选型 → 点取 → 预览 → 确定）

1. 在 OpenPlant Modeler 中打开或新建一个**三维**、公制的 DGN 模型。
2. 打开 **Utilities（实用工具）→ Python** 的 Python Editor。
3. 新建 Python Project，选择或复制 `security_fence_gate.py`，然后执行。
4. 在弹出的面板里选门型，并（可选）调整门洞净宽、转角：
   - **门型**：单扇门（默认 1.2 m）/ 双扇门（默认 4.27 m）；切换门型会把门洞净宽恢复成该门型的默认值；
   - **门洞净宽**：两门柱内表面之间的距离，默认 1200 / 4270；
   - **转角**：0° 时门洞沿模型 +X 方向，逆时针为正；
   - **反向**：整樘门绕 z 轴翻转 180°（等价于转角 +180°，门柱 45° 斜挑朝向随之翻转）；
   - **生成门柱**、**门柱增加混凝土基础**、**生成防攀悬臂与刺钢丝**：三个开关，默认全开。门扇的活页**始终生成**（不建门柱时也生成，连接到预埋柱位置）。
5. 在模型中点取**门洞中心的地面点**（点取位置的 Z 即地面标高），立即生成预览。
6. 看着模型里的预览调整面板选项，**改一次就自动重建一版**（旧的预览会被删掉，模型里始终只有一版）；想换位置直接再点一次，预览会移到新位置。
7. 觉得对了就点**【确定】**：当前这版预览就地保留，工具结束。
   点**【取消】**（或右键、直接关掉面板）则删除预览、放弃本次生成。

面板会显示当前预览的统计（门型、门洞净宽、转角、门扇数量与宽度、门柱根数、是否含基础 / 悬臂），命令提示区同时输出同样信息。生成期间面板控件会临时禁用，避免重复触发；若 45° 斜接的布尔运算失败，该端按平口处理并在提示里说明。

脚本按活动模型的 `MASTER_UNITS_PER_METRE` 换算，输入始终按 mm 解释，不要求把主单位设成 mm。

## 几何规则（局部坐标）

以点取点为原点建立局部坐标系：**x 沿门洞宽度、y 朝防攀悬臂一侧、z 竖直向上**。

| 项目 | 规则 |
| --- | --- |
| 门柱中心 | x = ±(门洞净宽 / 2 + 门柱外径 / 2) |
| 门扇 | 单扇居中；双扇左右对称，中缝留 20 间隙 |
| 门扇外缘 | 距门柱内表面 20 安装间隙 |
| 门框中心线 | 相对门扇外缘内缩 φ42.8 / 2 = 21.4，使门框外表面与门扇外缘齐平、上表面正好在 1800 |
| 斜撑 | 合页面下角 → 中缝面上角；双扇两条斜撑镜像 |
| 45° 斜接 | 每个角落的切平面过两根构件中心线交点，**外法向 = 另一根构件朝向管身的方向 − 本构件朝向管身的方向**，两根构件的法向相反；管身两端各沿轴线外伸 `MITRE_END_EXTENSION` 再切，切出**完整椭圆端面**，两根构件在角点处完整拼合、外角不留缺口 |
| 门柱悬臂 | 45° 斜挑：弯头 + 直段，只有门柱一端、不跨门洞 |
| 门扇悬臂 | 竖直段：两立柱从 1800 直上 450，3 道刺钢丝拉在两者之间 |
| 活页 | 每扇 3 个（高度 1/4、1/2、3/4）；销轴位于门扇外缘与门柱内表面之间缝隙的中点，两块连接板从门扇立柱中心线跨到门柱中心线（门柱不建模时仍伸到预埋柱位置） |

## 实现说明

- **预览 / 确定机制**（与 `安保围栏/security_fence_body.py` 相同）：`_build_security_gate_cell()` 在内存里把整樘门建完（**不写模型**），成功后 `commit()` 才 `AddToModel()`；`replace_security_gate()` 负责“先建新的一版、写进模型，再删掉上一版预览”。因此**新的一版构建失败时旧预览不会被删**，改选项不会把模型里的大门改没了。面板上保存着最近一次点取的位置和当前预览的 `EditElementHandle`，改选项时用它们重建；删除前先 `IsValid()` 判断句柄是否还有效（用户手动删掉或按了 Ctrl+Z 的情况）。
- **单元封装**：`_GateCellBuilder` 先创建孤立单元头，逐个 `AddChildElement`，最后 `AddChildComplete`；任何一步失败就整体放弃，不会在模型里留下半成品。
- **空心钢管**：外圆柱减内圆柱；内圆柱两端各外伸 2 mm，避免端面共面导致布尔减法失败。
- **空心弯头**：`DgnTorusPipe` 圆环管做同样的布尔减法，内弧向量基绕弯头所在平面的法向旋转 `2 mm / R`，因此内外弧始终共面，门洞朝向任意都能正确掏空。
- **45° 斜接**：门框四根构件按中心线端点**两端各沿轴线外伸 `MITRE_END_EXTENSION`** 创建实心圆柱，再用 `_create_cut_box()` 生成的**切刀方块**（背面贴在过角点的 45° 切平面上、沿外法向向外延伸 300 mm）做布尔减法，然后掏出内孔。外伸是为了让切平面切出**完整椭圆端面**（不外伸时端面只有半椭圆 + 角点处一块平口，两根构件拼不上、外角出现缺口）。切刀法向取"另一根构件朝向管身方向 − 本构件朝向管身方向"，两根构件各切掉朝向对方的一侧，45° 端面对焊拼合。切刀创建或布尔失败时该端退化为平口，生成不中断，并在面板提示里说明。
- **活页**：销轴是竖直实心圆柱（`_create_solid_cylinder`），连接板是水平矩形 Shape 经 `ThickenSheet` 拉伸的薄板；`_add_hinge()` 按门扇外缘与门柱内表面之间的缝隙定位销轴，连接板从门扇立柱中心线跨到门柱中心线。门柱不建模时活页照常生成（连接板仍伸到预埋柱位置）。
- **混凝土基础**：在门的局部坐标系里按底面四点创建矩形 Shape，再用 `SolidUtil.Modify.ThickenSheet` 沿 +Z 拉伸成实体，所以基础随门一起旋转，轮廓画在 -600 处、拉伸后顶面与地面齐平。
- **参数校验**：门洞净宽限制在 600–20000 mm；门型只接受 single / double；转角必须是有限数字。校验不通过时保留上一版预览并在面板报错。
- **选项防抖**：输入框每敲一个字符都会触发重建请求，`REGENERATE_DELAY_MS`（150 ms）内只执行最后一次。

## 已知限制

- 只建模**关闭状态**的门扇，不生成开启角度、门锁 / 插销、拉紧螺栓、蘑菇盖、底板和涂装；合页为**简化表示**（销轴 + 连接板），不是可运动机构。
- **不会自动打断已有围栏**：如果先用安保围栏插件沿整条路径生成了围栏，门洞位置的网片、张紧钢丝和刺钢丝仍然存在，需要手工在该处断开（删掉那一跨或把围栏路径拆成两段）。
- 门柱的 φ100 空心管与门扇的 φ42.8 管都是独立实体，不做焊接合并（整樘门是单元，不是布尔合体）。
- 门扇数量固定为 1（单扇）或 2（双扇），不支持子母门等其它组合。

## 调用方式

- 界面入口：`PyMain()`（脚本末尾有 `if __name__ == "__main__"`，在 Python Editor 中直接运行即可）。
- 编程调用：
  - `draw_security_gate(placement_point, options=None)`：直接生成并写入模型，返回统计字典；
  - `replace_security_gate(placement_point, options, previous_handle)`：预览用的重建接口，返回 `(新单元句柄, 统计字典, 是否删掉旧预览)`；
  - `_build_security_gate_cell(placement_point, options)`：只构建不写模型，返回 `(builder, 统计字典)`。
- `options` 为字典，缺省键取默认值：

  | 键 | 取值 | 默认 |
  | --- | --- | --- |
  | `gate_type` | `"single"` / `"double"` | `"single"` |
  | `opening_width` | 门洞净宽（mm），`None` 表示按门型取默认 | `None` |
  | `heading_deg` | 转角（度），0° 沿 +X | `0.0` |
  | `mirrored` | 悬臂是否改朝另一侧 | `False` |
  | `include_posts` | 是否生成门柱 | `True` |
  | `include_foundation` | 门柱是否带混凝土基础 | `True` |
  | `include_overhang` | 是否生成防攀悬臂与刺钢丝 | `True` |

## 几何自检

`_geometry_selftest.py` 用桩件模拟 MSPy API，**不需要 MicroStation**，任何 Python 3 都能跑：

```
python _geometry_selftest.py
```

覆盖门柱 / 门扇定位、45° 斜接切平面与切向、竖直悬臂与刺钢丝位置、活页数量与位置、菱形网裁剪、单位换算（毫米与英尺主单位）、选项开关、布尔失败降级、参数校验和面板选项解析，全部通过时输出 `ALL CHECKS PASSED`。改完 `security_fence_gate.py` 后建议重跑一遍。

这是一份**几何建模**插件，创建的是活动 OPM 模型中的 MicroStation SmartSolid 图元。若需要把它注册为带 Class / Tag / 规格属性的 OpenPlant 智能组件，还需结合项目使用的 OPM 类库、EC Schema 和目录规范。
