# Bentley_OPM_Plugin_wlp

为 **Bentley OpenPlant Modeler（OPM）** 开发的插件集合。多数目录是运行在 Bentley Power Platform Python 环境中的脚本；另有独立的 C# AddIn“型钢构件及支吊架模型生成工具”。

> 这些插件绝大多数是**几何建模**工具，生成的是活动 OPM 模型中的 SmartSolid 图元（`管道信息查询` 是例外，它是只读查询工具，不生成几何）。若需注册为带 Class / Tag / 规格属性的 OpenPlant 智能组件，还需结合项目使用的 OPM 类库、EC Schema 和目录规范。

## 环境要求

- Bentley OpenPlant Modeler（基于 MicroStation）
- Power Platform Python 环境（MSPy 模块）——仅 Python 插件需要
- 三维、公制 DGN 模型
- C# AddIn 另需：.NET Framework 4.8 + x64 编译环境、OpenPlant Modeler 2024 SDK（默认 `C:\Program Files\Bentley\OpenPlant 2024\IsometricsManager`）；**运行时不依赖 Python 环境**

## 通用使用方法

1. 在 OPM 中打开或新建一个**三维**、公制的 DGN 模型。
2. 打开 **Utilities（实用工具）→ Python** 的 Python Editor。
3. 新建 Python Project，选择或复制对应目录中的脚本，然后执行。
4. 在弹出窗口中设置参数，确认后在模型内点取放置点；右键可取消。
5. 每个脚本的**具体参数与几何规则**见各自目录下的 `README.md`。

> 注意：脚本按当前 DGN 的 `MASTER_UNITS_PER_METRE` 换算单位，因此输入尺寸统一按 mm 解释，不要求把主单位设成 mm。

C# AddIn 的使用方式不同（不经过 Python Editor）：把编译输出目录加入 `MS_ADDINPATH`，在 OPM 中输入 `MDL LOAD SteelSectionProbe` 加载，再用 `STEELPROBE SHOW` 打开工作区，之后从功能首页进入各功能页。详见下方「C# AddIn」一节。

## C# AddIn：型钢构件及支吊架模型生成工具

上面各目录是 Python 脚本，本目录是**唯一一个 C# 工程**：独立的 OpenPlant Modeler 2024 AddIn，运行时只加载 C# DLL，**不启动 Python、不读取同级 Python 工程**。它是原 `型钢截面生成器` 的 C# 重写与扩展（原目录已保留为 Python 版）。

- 工程：[`型钢构件及支吊架模型生成工具_CS/SteelSupportModeler.csproj`](型钢构件及支吊架模型生成工具_CS/SteelSupportModeler.csproj)（程序集名仍为 `SteelSectionProbe`，以兼容已有的 OPM 加载配置）
- 编译：`dotnet build SteelSupportModeler.csproj -c Release`（默认 SDK 根目录 `C:\Program Files\Bentley\OpenPlant 2024\IsometricsManager`，可用 `/p:BentleyRoot=` 覆盖）
- 加载：`MDL LOAD SteelSectionProbe`，然后 `STEELPROBE SHOW`（或 `STEELPROBE PLACE` 直达截面放置）
- 说明：[`型钢构件及支吊架模型生成工具_CS/README.md`](型钢构件及支吊架模型生成工具_CS/README.md)；接续开发前必读 [`型钢构件及支吊架模型生成工具_CS/AGENTS.md`](型钢构件及支吊架模型生成工具_CS/AGENTS.md)

功能以「可扩展的功能首页 + 独立功能页」组织，进入 `STEELPROBE SHOW` 后从首页选择，**除下列两个命令外没有额外的 Key-in**。

「未实现」的这些目前只有 Python 版（见 `管道支吊架` 目录）；C# 版目录名中的“支吊架”部分即指这块待移植的工作。

**关于验证状态（重要）**：上表「已实现」仅表示**功能代码完成且 Release 编译通过（0 错误 0 警告）**，**不代表已在 OPM 2024 中实测通过**。本项目已实测的部分是各功能的纯计算自检（`Development/*Check/`，均可用 `dotnet run --project ... -c Release` 运行，且已从 AddIn 编译中排除）；而 Bentley 运行时行为——EC 属性跨模型读取、实体布尔差集、真圆弧扫掠、Cell 写入、预览删除与 ItemType 汇总写入、另存为对话框——**全部仍需在 OPM 2024 中用真实 DGN 实测**。各功能需要实测的具体项见 [`型钢构件及支吊架模型生成工具_CS/README.md`](型钢构件及支吊架模型生成工具_CS/README.md) 各节末尾的说明。

### 与 Python 版的清单互通

C# 版与原 Python 版共用同一个 `PipeSupportComponents` ItemType 库和**同一套九个属性字段**（`RecordKind` / `SupportType` / `AssemblyTag` / `ComponentName` / `Specification` / `DesignLengthMm` / `Quantity` / `Unit` / `PipeNumber`），因此 C# 生成的支吊架可被 Python 版 `00-[支吊架统计].py` 统计，反之亦然。修改字段或统计口径时必须同步两侧。

### 型钢规格数据维护

可编辑的规格源在本 C# 工程内 [`型钢构件及支吊架模型生成工具_CS/Development/profile_catalog/`](型钢构件及支吊架模型生成工具_CS/Development/profile_catalog/)；改动后需运行 `python -B Development/export_profiles.py` 重新生成 [`Resources/profiles.bin`](型钢构件及支吊架模型生成工具_CS/Resources/profiles.bin) 再编译。**只改 `.py` 不会影响已编译的 DLL**，也不要在运行时依赖 Python。

## 排错

部分脚本在 Bentley 几何内核返回错误时会向各自目录写入 `*_debug_log.txt`，排查时请查看对应日志。
