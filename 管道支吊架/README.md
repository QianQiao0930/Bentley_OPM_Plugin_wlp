# 管道支吊架（OpenPlant Modeler MSPython）

把所有**管道支吊架**插件与清单工具集中在本目录，共用一套 ItemType 契约，因此
不同型式的支吊架（三角架、L 型管架，以及今后新增的）可以**一起统计**。

## 目录内容

> **【公共模块 · 请勿直接运行】**：标记该字样的文件没有独立入口，仅供其它插件
> `import` 调用，请勿在 OpenPlant Modeler / MicroStation 中直接加载运行。

顶层只保留各功能的**入口文件**；公共库、各功能几何库、命令注册表与单测统一
收纳在 `模块/` 下，并**按功能分子文件夹**，便于浏览。

## 公共 ItemType 契约

所有支吊架统一写入库 `PipeSupportComponents`，属性：

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `RecordKind` | 字符串 | `Assembly`（整组）/ `Component`（构件） |
| `SupportType` | 字符串 | 支吊架类型，如 `D5_D6-[三角架]` / `D7-[L形_倒L形架]` / `D8-[门型架_倒门型架（角钢和槽钢）]` / `D13-[门型架_倒门型架（H型钢）]` |
| `AssemblyTag` | 字符串 | 支吊架编号 |
| `ComponentName` | 字符串 | 构件名 |
| `Specification` | 字符串 | 规格 |
| `DesignLengthMm` | 双精度 | 设计长度 / 特征尺寸 |
| `Quantity` | 整数 | 数量 |
| `Unit` | 字符串 | 单位（件 / 套） |
| `PipeNumber` | 字符串 | 管道号（记录使用该支架的管道；默认空白，用户可在元素「属性 → Item Types」面板中自行填写） |

每个放置的支吊架在整组单元上写一条 `Assembly` 记录（用于按类型统计套数），
每个构件写一条 `Component` 记录（用于材料汇总）。属性值写在 ItemType 默认值里；
`PipeNumber` 在提供源管道号的工具中自动填写；没有管道号时留空。不同管道号使用不同 ItemType，避免复用默认值导致串号，用户也可逐实例修改。

## 使用

### 端焊三角架（三角架：选线 + 端板）
运行 `D5_D6-[三角架].py`：点选一条水平直线（横担上表面）→ 选子项 / E / 端板子项 →
预览 → 确定。清单写入公共库，`SupportType='D5_D6-[三角架]'`。
几何 / 数据逻辑在 `模块/端焊三角架/端焊三角架_选线_几何.py`（只出几何元素），
单元拼装与公共库写入在入口 `D5_D6-[三角架].py`；面板用共享 Tkinter 工具箱 `bentley_ui`；
不再依赖旧插件 `端焊三角架_选线版.py`，也不使用 PyQt5。

### L 型管架
运行 `D7-[L形_倒L形架].py`：点选 L 形折线（竖直线＝立杆轴线、水平线＝横担顶面）→
选子项 / 类型（1/2 立杆在下、3/4 立杆在上·吊架）→ 预览 → 确定。
清单写入公共库，`SupportType='D7-[L形_倒L形架]'`。

> 各插件面板的「导出 JSON 清单」导出的是**全部管道支吊架**的统一清单。

### 门型架（角钢和槽钢）（图 C.4-8 · 类型 1）
运行 `D8-[门型架_倒门型架（角钢和槽钢）].py`：点选一条**竖直线**（**整组门型架的中心线**）→
输入净距 **B** / 朝向 → 预览 → 确定。清单写入公共库，
`SupportType='D8-[门型架_倒门型架（角钢和槽钢）]'`。

尺寸约定（**B 为两立柱净距**，即内缘到内缘）：

| 尺寸 | 取值 | 说明 |
| --- | --- | --- |
| `H` | 所选竖直线的长度 | 由基座到横担顶面（固定管子的面） |
| `B` | 用户输入 | 两立柱内缘之间的净距；表 1 的查表参数 |
| `W` | 子项自动 | 立柱在横担长度方向的截面宽度 |
| `L` | `B + 2W + 30` | 横担下料长度 |
| 立柱下料长 | `H − 翼缘厚 − 10` | 角钢取肢厚 `t`、槽钢取翼缘厚 `tf`；立柱**非通长**，顶端留 10 焊接间隙 |

布置：所选竖直线为**整组中心线**，两立柱轴线关于它对称、分别在 `∓(B + W)/2`
处（轴线间距仍为 `B + W`）；横担以该线为中点**横跨两根立柱**、两端各超出立柱
外缘 **15 mm**，顶面落在高度 `H`。两根立柱同长且互为镜像。

立柱与横担**背靠背**连接：

- 角钢子项（A / B / C）：横担竖直肢挂在 `+v` 侧（`v ∈ [W/2 − t, W/2]`）；立柱
  **镜像**到竖直肢外侧，立柱 u-w 平面肢的**背面**与横担竖直肢的**背面**同在
  `v = W/2` 相贴（两角钢背靠背，立柱截面整体落在 `v ∈ [W/2, W/2 + W]`）。
  立柱**不是通长**——最高点止于 `H − t − 10`，比横担水平肢低 **10 mm** 留作施焊，
  因此横担不落在立柱顶面上，力经「立柱肢 ↔ 横担竖直肢」的贴合焊缝下传，
  搭接段高度 `W − t − 10`（A 34 / B 58 / C 80）。
  两根立柱**互为镜像**（右柱在 u 方向镜像），开口都朝门架外。
- 槽钢子项（D / E）：横担腹板在 `−v` 端（`v ∈ [−B/2, −B/2 + tw]`，背面朝
  `−v`）；立柱沿 `−v` 平移一个翼缘宽 `B`，其腹板落在 `v ∈ [−B/2 − tw, −B/2]`、
  背面朝 `+v`，两块腹板的**背面**在 `v = −B/2` 相贴（背靠背，翼缘各自朝外）。
  同样**非通长**——顶端止于 `H − tf − 10`，搭接段高度 `Hch − tf − 10`
  （[14a 120.5 / [20a 179）。

- 竖直线不能定出朝向，故用面板的「朝向」指定门架平面（0° = 世界 +X）。
- 子项见表 2：`A` ∠50×6、`B` ∠75×7、`C` ∠100×10、`D` [14a、`E` [20a；
  允许垂直荷载按表 1 查（立柱、横担均为同一子项）。
- 槽钢子项（D / E）的立柱与横担腹板均竖直、在门架平面内，故 `W` 取型钢高度
  `H`（[14a → 140、[20a → 200）。
- 倒门形架（类型 3/4，立柱在上）尚未实现。
- 键入命令：`PYPORTALFRAME PLACE` / `PYPORTALFRAME EXPORT`。

### 门型架（H型钢）（图 C.4-8 · H 型钢 · 类型 1）
运行 `D13-[门型架_倒门型架（H型钢）].py`：点选一条**竖直线**（**整组门型架的中心线**）→
输入横担全长 **L** / 朝向 → 预览 → 确定。清单写入公共库，
`SupportType='D13-[门型架_倒门型架（H型钢）]'`。

尺寸约定（**L 为横担全长**）：

| 尺寸 | 取值 | 说明 |
| --- | --- | --- |
| `H` | 所选竖直线的长度 | 由基座到横担顶面（固定管子的面） |
| `L` | 用户输入 | 横担全长；表 1 的查表参数之一 |
| `B` | 自动 | 两立柱净距 `B = L − 2×50 − 2×立柱截面高` |
| 立柱下料长 | `H − 横担截面高` | 柱顶顶焊横担下翼缘下表面 |

布置：所选竖直线为**整组中心线**，两立柱轴线关于它对称、分别在
`∓(L − 100 − 立柱截面高)/2` 处；横担以该线为中点**横跨两根立柱**、两端各超出
立柱外缘 **50 mm**（图上 `50 (TYP.)`），顶面落在高度 `H`。

- 立柱与横担的**腹板同处于门架平面内**（v = 0）、翼缘对称于该平面，故立柱
  顶面直接顶焊在横担下翼缘的下表面上；两立柱截面相同、无需镜像。
- 子项见表 1：`A` H100×100×6×8、`B` H150×150×7×10、`C` H200×200×8×12、
  `D` H250×250×9×14；允许垂直荷载按表 1 以 **H 与 L** 双参数查（H 向下取
  表列值、L 向上取列）。
- 竖直线不能定出朝向，故用面板的「朝向」指定门架平面（0° = 世界 +X）。
- 倒门形架（类型 3/4，立柱在上）尚未实现。
- 键入命令：`PYPORTALFRAMEH PLACE` / `PYPORTALFRAMEH EXPORT`。

### T 形架（类型 1 / 类型 2）
运行 `D12_G4-[T形_倒T形架].py`：点选一条**竖直线**（立柱轴线；允许 **±5° 以内**的轻微倾斜，
非竖直线会被拒绝）→ 选择**类型** / 输入横担全长 **L** / 朝向 → 预览 → 确定。
清单写入公共库，`SupportType='D12_G4-[T形_倒T形架]'`。

尺寸约定（**H 为所选竖直线长度**，L 由用户输入）：

| 尺寸 | 取值 | 说明 |
| --- | --- | --- |
| `H` | 所选竖直线长度 | 立柱长；取两端 Z 差 |
| `L` | 用户输入 | 横担全长；表 1 / 表 2 的查表参数之一 |
| 横担方向 | 世界水平、垂直于立柱 | 由面板「朝向」给定（0° = 世界 +X） |
| 立柱下料长 | 见「连接方式」 | 角钢非通长（留 10）、H 型钢端面焊 |

布置：单根立柱居中（轴线即所选竖直线），横担以该线为中点、两端各 `L/2`，
**长边水平、用于放管道**。两类型：

- **类型 1（正 T 形架）**：立柱在横担**下**；所选竖直线**下端为基座**（落在已有
  钢结构上），**上端为横担管位面**（坐管高度 H）。
- **类型 2（倒 T 形吊架，立柱在上）**：立柱在横担**上**；所选竖直线**下端为横担
  管位面**（管位朝上，**与类型 1 同向**），**上端接已有结构**；立柱向上到上端。

立柱与横担同规格（构件 A），连接方式同门型架（两类型的横担截面同向：角钢水平肢 /
H 型钢上翼缘朝上作管位面）：

- 子项见表 3：`A` ∠50×6、`B` ∠75×7、`C` ∠100×10、`D` H100×100×6×8、
  `E` H150×150×7×10、`F` H200×200×8×12、`G` H250×250×9×14；立柱与横担同规格。
- **角钢子项（A~C）背靠背**：立柱的 u-w 平面肢与横担竖直肢背面相贴、留 10 mm
  施焊间隙。下料长：类型 1 `H − 肢厚 − 10`（立柱上端在横担水平肢下）；
  类型 2 `H + (W − 肢厚 − 10)`（立柱下探到管位面以下与横担竖直肢搭接）。

### N 系列 · 设备上生根的双三角架（N4）
运行 `N4-[设备上生根双三角架].py`：绘制并**点选一条水平直线**作为整组**中心线**
（径向）→ 选**类型** / **子项** / **H** / **L2** / **L3** / **L4** / **系列**，
勾选**保留辅助线** → 预览 → 确定。清单写入公共库，
`SupportType='N4-[设备上生根双三角架]'`。几何 / 数据逻辑在 `模块/双三角架/`。

辅助线约定：**线长 = L1**（立管中心线 → 端板外表面）；线方向 = 径向；两根横担关于

  斜撑各一块，共 4 块。
- **筋板**：10 mm 厚通长筋板，**每根横担 3 个**（斜撑交点 + 两根构件C 交点），共 6 个。
- `H`（≥MIN.H）与 `L2`（≥MIN.L2）由面板输入；横担外端到斜撑交点水平余量 **≥150**。
