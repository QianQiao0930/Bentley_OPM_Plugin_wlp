# 管道支吊架（OpenPlant Modeler MSPython）

把所有**管道支吊架**插件与清单工具集中在本目录，共用一套 ItemType 契约，因此
不同型式的支吊架（端焊三角架、L 型管架，以及今后新增的）可以**一起统计**。

## 公共 ItemType 契约

所有支吊架统一写入库 `PipeSupportComponents`，属性：

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `RecordKind` | 字符串 | `Assembly`（整组）/ `Component`（构件） |
| `SupportType` | 字符串 | 支吊架类型，如 `端焊三角架` / `L型管架` / `门型架（角钢和槽钢）` / `门型架（H型钢）` |
| `AssemblyTag` | 字符串 | 支吊架编号 |
| `ComponentName` | 字符串 | 构件名 |
| `Specification` | 字符串 | 规格 |
| `DesignLengthMm` | 双精度 | 设计长度 / 特征尺寸 |
| `Quantity` | 整数 | 数量 |
| `Unit` | 字符串 | 单位（件 / 套） |

每个放置的支吊架在整组单元上写一条 `Assembly` 记录（用于按类型统计套数），
每个构件写一条 `Component` 记录（用于材料汇总）。属性值写在 ItemType 默认值里。

## 使用

### 端焊三角架（选线 + 端板）
运行 `端焊三角架_选线版_端板.py`：点选横担上表面直线 → 选子项 / L1 / E / 端板
子项 → 预览 → 确定。清单写入公共库，`SupportType='端焊三角架'`。

### L 型管架
运行 `L型管架.py`：点选 L 形折线（竖直线＝立杆轴线、水平线＝横担顶面）→
选子项 / 类型（1/2 立杆在下、3/4 立杆在上·吊架）→ 预览 → 确定。
清单写入公共库，`SupportType='L型管架'`。

> 各插件面板的「导出 JSON 清单」导出的是**全部管道支吊架**的统一清单。

### 门型架（角钢和槽钢）（图 C.4-8 · 类型 1）
运行 `门型架（角钢和槽钢）.py`：点选一条**竖直线** → 输入净距 **B** / 朝向 →
预览 → 确定。清单写入公共库，`SupportType='门型架（角钢和槽钢）'`。

尺寸约定（**B 为两立柱净距**，即内缘到内缘）：

| 尺寸 | 取值 | 说明 |
| --- | --- | --- |
| `H` | 所选竖直线的长度 | 由基座到横担顶面（固定管子的面） |
| `B` | 用户输入 | 两立柱内缘之间的净距；表 1 的查表参数 |
| `W` | 子项自动 | 立柱在横担长度方向的截面宽度 |
| `L` | `B + 2W + 30` | 横担下料长度 |
| 立柱下料长 | `H − 翼缘厚 − 10` | 角钢取肢厚 `t`、槽钢取翼缘厚 `tf`；立柱**非通长**，顶端留 10 焊接间隙 |

布置：左立柱轴线即所选竖直线，右立柱轴线在 `B + W` 处；横担**横跨两根立柱**、
两端各超出立柱外缘 **15 mm**，顶面落在高度 `H`。两根立柱同长同向。

立柱与横担**背靠背**连接：

- 角钢子项（A / B / C）：横担竖直肢挂在 `+v` 侧（`v ∈ [W/2 − t, W/2]`）；立柱
  **镜像**到竖直肢外侧，立柱 u-w 平面肢的**背面**与横担竖直肢的**背面**同在
  `v = W/2` 相贴（两角钢背靠背，立柱截面整体落在 `v ∈ [W/2, W/2 + W]`）。
  立柱**不是通长**——最高点止于 `H − t − 10`，比横担水平肢低 **10 mm** 留作施焊，
  因此横担不落在立柱顶面上，力经「立柱肢 ↔ 横担竖直肢」的贴合焊缝下传，
  搭接段高度 `W − t − 10`（A 34 / B 58 / C 80）。
  两根立柱**互为镜像**（右柱在 u 方向镜像），开口都朝门架外。
- 槽钢子项（D / E）：横担腹板在 `−v` 端（`v ∈ [−B/2, −B/2 + tw]`，背面朝
  `−v`）；立柱沿 `−v` 平移一个翼缘宽 `B`，其腹板落在 `v ∈ [−B/2 − tw, −B/2]`、
  背面朝 `+v`，两块腹板的**背面**在 `v = −B/2` 相贴（背靠背，翼缘各自朝外）。
  同样**非通长**——顶端止于 `H − tf − 10`，搭接段高度 `Hch − tf − 10`
  （[14a 120.5 / [20a 179）。

- 竖直线不能定出朝向，故用面板的「朝向」指定门架平面（0° = 世界 +X）。
- 子项见表 2：`A` ∠50×6、`B` ∠75×7、`C` ∠100×10、`D` [14a、`E` [20a；
  允许垂直荷载按表 1 查（立柱、横担均为同一子项）。
- 槽钢子项（D / E）的立柱与横担腹板均竖直、在门架平面内，故 `W` 取型钢高度
  `H`（[14a → 140、[20a → 200）。
- 倒门形架（类型 3/4，立柱在上）尚未实现。
- 键入命令：`PYPORTALFRAME PLACE` / `PYPORTALFRAME EXPORT`。

### 门型架（H型钢）（图 C.4-8 · H 型钢 · 类型 1）
运行 `门型架（H型钢）.py`：点选一条**竖直线** → 输入横担全长 **L** / 朝向 →
预览 → 确定。清单写入公共库，`SupportType='门型架（H型钢）'`。

尺寸约定（**L 为横担全长**）：

| 尺寸 | 取值 | 说明 |
| --- | --- | --- |
| `H` | 所选竖直线的长度 | 由基座到横担顶面（固定管子的面） |
| `L` | 用户输入 | 横担全长；表 1 的查表参数之一 |
| `B` | 自动 | 两立柱净距 `B = L − 2×50 − 2×立柱截面高` |
| 立柱下料长 | `H − 横担截面高` | 柱顶顶焊横担下翼缘下表面 |

布置：左立柱轴线即所选竖直线，右立柱轴线在 `L − 100 − 立柱截面高` 处；横担
**横跨两根立柱**、两端各超出立柱外缘 **50 mm**（图上 `50 (TYP.)`），顶面落在
高度 `H`。

- 立柱与横担的**腹板同处于门架平面内**（v = 0）、翼缘对称于该平面，故立柱
  顶面直接顶焊在横担下翼缘的下表面上；两立柱截面相同、无需镜像。
- 子项见表 1：`A` H100×100×6×8、`B` H150×150×7×10、`C` H200×200×8×12、
  `D` H250×250×9×14；允许垂直荷载按表 1 以 **H 与 L** 双参数查（H 向下取
  表列值、L 向上取列）。
- 竖直线不能定出朝向，故用面板的「朝向」指定门架平面（0° = 世界 +X）。
- 倒门形架（类型 3/4，立柱在上）尚未实现。
- 键入命令：`PYPORTALFRAMEH PLACE` / `PYPORTALFRAMEH EXPORT`。

### 统计插件
运行 `支吊架统计.py`：显示当前活动 DGN 的支吊架总套数与按类型分布，并可
- **导出 Excel 清单**：一个 `.xlsx`，含「汇总 / 支吊架表 / 材料汇总表」三个工作表；
- **导出 JSON**：统一清单。

## 添加新的支吊架插件

```python
import 支吊架公共库 as psb
psb.attach_components(
    cell,
    support_type='××支吊架',        # 中文显示名
    support_code='XXX',             # ASCII 代号（ItemType 命名）
    assembly_tag=编号, assembly_spec=规格,
    components=[{'code', 'name', 'specification', 'length', 'quantity'}, ...],
)
```

接入后即自动出现在统计插件的清单里。
