# 轻便消防水龙柜插件（15S202 第 53 页）

`轻便消防水龙柜.py` 在 Bentley OpenPlant Modeler / MicroStation 的活动三维 DGN
模型中，按国家标准图集 **15S202《室内消火栓安装》第 53 页"轻便消防水龙柜（二）"**
（规格 1200×550×160）快速创建三维模型。整套柜体封装为名为 `LightHoseCabinet`
的普通单元（Orphan Cell），并挂接记载《主要器材表》8 项器材及**用户输入的箱内
灭火器型号与数量**的 ItemType。

## 图集依据

- 图集号：**15S202**，第 **53** 页，轻便消防水龙柜（二）。
- 柜体规格：**1200（高）× 550（宽）× 160（进深）**，钢制柜体、门面喷塑。
- 上部为轻便消防水龙卷盘 P380 及阀门、直流喷雾喷枪；下部储物区放置灭火器，
  灭火器型号与数量由用户输入。

## 坐标约定

| 轴 | 含义 | 默认 |
| --- | --- | --- |
| X | 柜宽（长边） | 550 |
| Y | 进深（短边） | 160 |
| Z | 柜高 | 1200 |

点取点为**柜体底部前侧中心**：柜体沿 ±X 对称、沿 +Y 向后、沿 +Z 向上，
正面朝 **-Y**（与其他消防构件插件一致）。尺寸单位统一按 **mm** 解释，
脚本按当前 DGN 的 `MASTER_UNITS_PER_METRE` 自动换算。

## 生成构件

| 构件 | 几何规则 |
| --- | --- |
| 钢制柜体 | 直角外壳扣除内腔，前端开口；壁厚 1.5（**无圆角**） |
| 上下隔板 | 位于下部储物区顶面（默认 Z=550），板厚 1.5，随柜体宽度通铺 |
| 柜门 | 厚 1.5，正面设上、下两处矩形观察窗（分别对准卷盘与灭火器），中部实板带竖向门把手 |
| 柜门标识 | "轻便消防水龙柜" + "火警电话 119"，朝 -Y |
| 消防水龙卷盘 | 直径 **P380**，轴线沿 Y；轮毂 φ90 + 两片侧板；中心距左 200、距顶 200 |
| 灭火器 | 型号与数量**由用户输入**（默认 `MFZ/ABC4`、2 具），φ140、高 460，按数量均布于下部储物区，瓶口 φ40；数量受柜宽限制（默认柜宽最多 3 具） |
| 卷盘给水管 | **DN25**（外半径 17）水平支管，位于**隔板上方 100**（图集 I-I 的 100 标注，即默认 Z=650），自柜体左侧穿出并外伸 120；含阀体 + 手轮、穿墙管套与**螺纹接口**（DN25 外螺纹短节，不做法兰片） |
| 直流喷雾喷枪 | 枪管沿 X + 下挂手柄，示意布置 |

内部设备为**示意几何**（标准件、软管等不做精确外形），可通过界面开关关闭，
只保留柜体、隔板与柜门。

## 器材表与 ItemType

生成时给柜体单元挂接一个 **ItemType 构件项**，属性定义写入 DGN 的
`FireProtectionComponents` 库，ItemType 名形如
`LightHoseCabinet_15S202_550x160x1200_MFZ_ABC4x2`（含灭火器型号与数量）。
属性除尺寸、型号与坐标约定外，`BomJson` 字段保存完整清单
（`ensure_ascii=False` 的 JSON 字符串）：

| 编号 | 名称 | 材质 | 规格 | 单位 | 单柜数量 |
| --- | --- | --- | --- | --- | --- |
| 1 | 轻便消防水龙柜 | 钢 | 550×160×1200（随实际尺寸） | 个 | 1 |
| 2 | 轻便消防水龙卷盘 | 钢喷塑 | P380 | 个 | 1 |
| 3 | 轻便消防水龙 | 衬胶 | LQG16-30 | 条 | 1 |
| 4 | 直流喷雾喷枪 | 全铜 | 当量喷嘴直径 φ6 | 支 | 1 |
| 5 | 快速接口 | 全铜 | 成品 | 个 | 1 |
| 6 | 快速接头 | 钢或铜 | DN25 | 个 | 1 |
| 7 | 阀门 | 全铜 | DN25 | 个 | 1 |
| 8 | 管套 | 钢（扣压成型） | 成品 | 个 | 1 |
| 9 | 手提式灭火器 | 用户配套 | 用户输入的型号（如 `MFZ/ABC4`） | 具 | 用户输入（>0 时生成该行） |

> 注：图集原表第 1 项规格为 1200×550×160；建模时按用户输入的柜体尺寸生成，
> 因此 `BomJson` 中的柜体规格会随输入变化。灭火器行仅在数量大于 0 时出现。

## 统计与导出

面板提供三个清单操作，均在活动 DGN 内按 ItemType 扫描统计：

- **统计当前模型**：汇总水龙柜数量、器材合计与**灭火器合计**，弹窗显示。
- **导出 JSON 清单**：写出 `轻便消防水龙柜_bom.json`，含导出时间、图集、
  柜型汇总、器材合计、灭火器合计与逐元素明细（含灭火器型号/数量）。
- **导出 Excel 清单**：写出 `轻便消防水龙柜_bom.xlsx`，包含"汇总"（柜型 +
  主要器材表 + 灭火器总数）与"明细"（逐元素，含灭火器型号/数量）两个工作表，
  无需安装第三方 Excel 库。

跨柜合计按 **（编号, 名称, 材质, 规格, 单位）** 分组：每柜数量乘以该柜的
`CabinetQuantity` 后求和；灭火器行同样参与合计。若某元素的 `BomJson` 缺失，
则退回按尺寸与灭火器属性重建清单。

## 使用方法

1. 在 OpenPlant Modeler 中打开三维、公制 DGN 模型。
2. 打开 **Utilities（实用工具）→ Python** 的 Python Editor，运行
   `轻便消防水龙柜.py`。
3. 在弹出的窗口设置规格参数（默认即图集规格 1200×550×160），填写**灭火器型号**
   与**数量**（默认 `MFZ/ABC4`、2 具），可关闭"生成内部设备"；
   点击 **下一步：点取位置**。
4. 在模型中点取柜体底部前侧中心点，程序生成柜体并写入 ItemType；
   右键取消定位。
5. 需要清单时，先放置若干柜体，再运行脚本点击 **统计当前模型** /
   **导出 JSON 清单** / **导出 Excel 清单**。

参数保存在 `轻便消防水龙柜_上次选型.json`，下次运行自动带出。

## 几何自检

`_geometry_selftest.py` 不依赖 Bentley 运行时，通过 AST 抽取纯计算函数验证：
柜体布局对称性、P380 卷盘位于距左/距顶 200 且不越界、灭火器按输入数量均布且不
穿出隔板、灭火器数量超限校验、DN25 给水管位于隔板上方 100 并自柜体左侧伸出、
棱柱截面圆度与轴向、含灭火器的清单行、`BomJson` 往返解析、跨柜合计与尺寸校验。

```
python _geometry_selftest.py
# light_hose_cabinet geometry self-test: OK
```

## 已知限制

- 内部设备为标准件示意几何，卷盘侧板未建辐条，软管不做盘绕实体。
- 柜体为竖直放置的轴对齐体，暂不支持沿任意墙面旋转。
- 生成的柜体为 MicroStation SmartSolid / Cell；如需注册为带 OPM Class / EC
  规格属性的智能组件，还需结合项目使用的 OPM 类库与目录规范。
- 几何内核返回错误时会向本目录写入 `轻便消防水龙柜_debug_log.txt`。
