## 回退方式

### 方式 1：从本文件夹复制回去（最快，不需要 git）

```powershell
$dst = 'E:\CODE\Bentley_Plugin\Bentley_OPM_Plugin_wlp'
$bak = Join-Path $dst '旧版本脚本\弯头耳轴_HVAC前_20260928'
$sup = Join-Path $dst '管道支吊架'
# 弯头耳轴四件
foreach ($f in 'F2-[水平弯头的竖直耳轴].py','F2-[竖直弯头的竖直耳轴].py',
               'F4-[竖直弯头的水平耳轴].py','F5-[水平弯头的水平耳轴].py') {
    Copy-Item -LiteralPath (Join-Path $bak $f) -Destination $sup -Force
}
# 公共逻辑与弯头垫板
Copy-Item -LiteralPath (Join-Path $bak 'elbow_selection_logic.py') `
          -Destination (Join-Path $sup '模块\竖直弯头的竖直耳轴') -Force
Copy-Item -LiteralPath (Join-Path $bak '弯头垫板.py') -Destination $sup -Force
Copy-Item -LiteralPath (Join-Path $bak '模块_弯头垫板\弯头垫板_几何.py') `
          -Destination (Join-Path $sup '模块\弯头垫板') -Force
```

复制完刷新 OPM 的 Python 缓存（重启 Python Editor 或重新运行脚本）即可。

## 备注

- `elbow_selection_logic.py`、`弯头垫板_几何.py` 的改动都是**向后兼容**的：新增参数都有默认值（`main_label` / `base_mm` / `od_override_mm` / `size_label`），管道弯头与管件垫板的老行为、报错文案不变。
- 但工具文件与几何模块要**成对回退**：只回退 `elbow_selection_logic.py` 而留着 4 个耳轴工具，风管分支会报 `AttributeError`；只回退 `弯头垫板_几何.py` 而留着 `弯头垫板.py`，会因 `od_override_mm` 关键字不存在而报 `TypeError`。
- 只回退工具文件、不回退公共模块则没问题：公共模块的新参数没人用而已。
- 单测 `test_hvac_duct_elbow.py` 依赖新接口，回退时请一并删除或还原。
