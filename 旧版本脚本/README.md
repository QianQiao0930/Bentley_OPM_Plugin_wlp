# 旧版本脚本（冻结归档）

这里存放**已废弃的入口脚本**，以及它们**归档时刻的依赖副本** —— 目的是让这些老脚本
脱离 `管道支吊架/` 也能在自己的文件夹里独立运行 / 测试。

## 目录内容

| 路径 | 说明 |
| --- | --- |
| `D5_D6-[三角架].py` | 端焊三角架**旧入口**（只实现 D5，`SupportType='D5_D6-[三角架]'`）。等效功能已被 `管道支吊架/D5_D6_G12_D19-[三角架（端焊_侧焊_锚固_双槽钢）].py` 覆盖（D5/D6/G12/D19 四架型） |
| `bentley_ui/` | 共享 Tkinter 面板工具箱（`glass.py` + `__init__.py`）—— 副本 |
| `模块/公共/混凝土锚板.py` | G2 混凝土锚板 + 膨胀锚栓建模库 —— 副本 |
| `模块/公共/支吊架公共库.py` | 公共 ItemType 契约与清单导出 —— 副本 |
| `模块/端焊三角架/端焊三角架_选线_几何.py` | 选线 + 端板几何库 —— 副本 |
| `模块/日志/`、`模块/输出/` | 运行时自动创建（老脚本自己的日志与清单导出） |

## 怎么跑

和以前完全一样：在 OpenPlant Modeler / MicroStation 里直接运行 `D5_D6-[三角架].py`
（入口里的 `PyMain` 会自动把本文件夹的 `模块/公共`、`模块/端焊三角架`、以及本文件夹
（`bentley_ui` 所在处）加入 `sys.path`）。日志写在本文件夹的 `模块/日志/`。

**只依赖本文件夹内的副本**：改 `管道支吊架/` 里的同名模块（几何库、公共库、bentley_ui）
不会影响这里的运行。

## 注意

1. **这是冻结副本**，不要在这里同步上游修改。要改老脚本的行为，请改这里并单独验证；
   新功能请加到 `管道支吊架/` 的现行入口。
2. 相对上游版本**唯一的代码改动**是入口脚本里的 `REPO_ROOT`：由"上一级目录"改为
   "本文件夹"，这样 `bentley_ui` 也在包内、整个文件夹可以整体搬走。归档时其余内容
   与 `管道支吊架/` 当时的版本逐字节一致（依赖是 `Copy-Item` 原样复制）。
3. **不要和现行插件在同一个 MicroStation 会话里混用**：Python 的模块缓存按模块名生效，
   谁先加载谁占位（`端焊三角架_选线_几何` / `混凝土锚板` / `支吊架公共库` / `bentley_ui`
   这几个名字在两边同名）。要测老脚本就开一个干净会话先跑它，反之亦然。
4. 老脚本写进模型的 `SupportType` 仍是 `D5_D6-[三角架]`，ItemType 库名仍是
   `PipeSupportComponents` —— 与现行插件写的是同一份公共库，历史记录照旧能被
   `00-[支吊架统计]` 统计到一起（只是按类型分开汇总）。
5. 以后再有废弃入口，直接放进本文件夹，并把它当时的依赖副本补进来（若与本文件夹已有的
   副本同名但版本不同，需另建子文件夹，避免互相覆盖）。
