# PipeAlign 管道标高对齐面板 — UI 优化交接说明

> 目标读者：接手的 AI（Claude / GPT / Cursor 等）
> 交付物：480×960 竖版停靠面板，用于 Bentley MicroStation OpenPlant 管道支吊架插件

---

## 1. 先读这个：尺寸是硬约束

面板固定 **480 宽 × 960 高**，作为 CAD 软件侧边停靠面板使用。

**这不是随便定的数字**——当前每个区块的高度是算过的，5 个卡片 + 底栏正好填满 960。
所以：

- **不要改面板宽高**
- 增删任何控件时，必须复核底部是否溢出
- 如果内容确实放不下，优先压缩行高和padding，而不是加宽面板

---

## 2. 现在长什么样

5 个卡片，自上而下：

| # | 区块 | 关键内容 |
|---|------|---------|
| 01 | 基准管 | 管号 + 规格 + 「选择基准管」内联按钮 |
| 02 | 对齐方式与表面模式 | 对齐基准 / 表面模式 / 水平容差 + 嵌套的「移动范围」单选组 |
| 04 | 目标管 | 2×2 按钮网格 + 已选计数 |
| 05 | 预览 | 两个勾选项 + 刷新/清除图标按钮 |
| 05 | 管道明细 | 弹性高度卡片列表（内滚动）+ 底部读数摘要 |

底栏固定：`应用`（主操作，填满剩余宽度）/ `重置` / `保存参数` + 一行操作指引。

## 3. 业务背景（判断取舍时需要）

这是**工程精度工具**，不是消费级 App。用户是管道支吊架设计工程师，在 CAD 里
逐根管道核标高。判断一个设计改动好不好，标准是：

- **数值必须易读易比对**——标高值、偏差值要能竖着扫下来
- **状态必须一眼可辨**——哪根要动、哪根不用动
- **不能有猜测**——插件不会替用户推断表面模式，未选就是未选
- **不能有装饰**——任何不服务于「看懂数字 / 做决定」的元素都是浪费像素

据此已做过几个判断，供你参考：

- **9列表格改成了卡片列表**。480宽放不下 9 列，卡片让每根管道的关键信息
  能独立成块扫读。
- **Z位移输入框被删了**。因为选中「锁 Z 轴」时它恒为禁用态，是个死控件。
- **数值全部用等宽字体并右对齐成列**。原来中文标签会冲散数字基线。

## 4. 配色规则

浅色工程主题，配色**采样自用户现有的 C# 工具界面**（型钢构件及支吊架
模型生成工具），不是凭空设计。请沿用这套色，不要改成深色或彩色风格。

```
页面底      #F5F6F8
卡片底      #FFFFFF
卡片描边    #E2E7EE
控件描边    #C9D3E0
主按钮      #2A3644   ← 深蓝灰，不是蓝色
标题文字    #1F2A3D
标签文字    #5B6472
辅助文字    #909BA8
品牌橙      #E0A800
状态蓝      #457AAB
圆角        4~6px（刻意小，扁平工程风）
```

### 状态色在浅底上要降饱和

这是从深色方案迁过来时踩过的坑，务必遵守：

| 语义 | 文字 | 背景 | 不能用|
|---|---|---|---|
| 已对齐 / 达标 | `#3D7A37` | `#E8F0E6` | ~~`#35ED7E`~~ 电光绿在白底上刺眼 |
| 需移动 / 警示 | `#9A6F14` | `#FDF3E0` | ~~`#EC48BD`~~ 品红过于跳脱 |

## 6. 反馈时请遵守的规矩

1. **改配色只动 `:root` 变量**，不要改HTML 里的硬编码色值，否则主题会失控。
2. **不要动 480×960**，增删控件后必须确认底部不溢出。
3. **保留状态色的降饱和处理**（见第 4 节），别"优化"回高饱和。
4. **不要加装饰性元素**——渐变、阴影、插画、圆角膨胀，在这个工具里都是负分。
5. **数值区的等宽字体和右对齐是功能性的**，不是风格选择，不要"简化"掉。
6. 如果你认为某个设计决策有问题，**先说明理由再改**，特别是涉及工程读数
   准确性的部分。

---

## 7. 常见优化方向（供参考，不必全做）

- 明细卡片当前固定显示 3 张 + 「展开其余 2 根」，可考虑虚拟滚动
- 「水平容差」单位硬编码为 mm，若要支持 imperial 需加单位切换
- 底栏「保存参数」目前无状态反馈，可加保存成功的 toast
- 单选组「锁 Z 轴」选中态对比度在浅底上偏弱，可考虑加强
- 所有控件尚无键盘焦点态，若要支持纯键盘操作需补focus ring
