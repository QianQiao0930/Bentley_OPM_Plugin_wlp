# 管道对齐

按一根**基准管**的标高，把一批**目标管**的管底 / 管中心 / 管顶对齐过去。

本目录**不再包含独立的 C# AddIn 工程**：管道对齐功能已集成到 [`型钢构件及支吊架模型生成工具_CS`](../型钢构件及支吊架模型生成工具_CS)（`STEELPROBE SHOW` 首页「管道标高对齐」模块，`MDL LOAD SteelSectionProbe` 加载），共用的 `PipeAlignment/` 分层代码只在大工程里维护，其行为（连通组整体移动、锁 Z、乙字弯头平移、自动预览）以大工程为准。

本目录现在只保留**需求与过程资料**：

- `管道对齐插件开发指南.md` —— 需求与开发规范（唯一需求来源）
- `管道对齐功能评估_2026-10-04.md` —— 功能评估记录
- `锁Z移动与撤销修复_2026-10-04.md` —— 2026-10-04 版实机验证与更新说明

原独立工程 `PipeAlign_CS/` 及其配套 `Development/`（ApiDump / ApiProbe / PipeAlignCheck / UiLayoutCheck / UndoCheck / WritebackCalls）与 `ui-share/` 已于 2026-10-15 删除；完整历史代码仍可从 git 历史与 `迁移备份/管道对齐集成_20261004/` 恢复。两个版本曾共用配置与日志，不得同时点取的提示随独立工程一并作废。
