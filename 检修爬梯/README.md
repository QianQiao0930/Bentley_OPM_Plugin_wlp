# 检修爬梯插件（移动式登高平台梯）

`maintenance_ladder.py` 在 Bentley OpenPlant Modeler / MicroStation 的活动 3D 模型中，按点选位置创建一台**整装移动式检修爬梯**（参考实物照片）：

- **45° 斜梯**：两侧斜梁 + 花纹钢板踏步；
- **顶部平台 1 m × 1 m**：平台面标高默认 **2000**；
- **平台护栏**（后侧 + 左右两侧）与**斜梯扶手**（两侧）；
- **矩形底架 + 4 个万向脚轮**（可开关），可选斜撑。

## 几何约定

放置点为**底架中心在地面（脚轮落地平面）上的投影**。整台爬梯以该点为中心，向**爬升方向**（水平，界面参数“水平角”，`0° = +X`，`90° = +Y`）展开：

- 局部坐标 `n` = 爬升方向、`t` = 梯宽方向、`z` = 竖直向上，满足 `n × t = z`；
- 斜梯自底架前缘（`n = toe`）爬升到平台前缘，**与水平面成 45°**；
- 平台位于后段，平台面标高 = 平台高度（默认 2000，自地面起）。

> 带脚轮时，脚轮把底架抬高一个轮径（默认 125），45° 的斜梯指的是「底架 → 平台」的实际爬升段；平台面仍然落在 2000。

## 建模假定

- 平台高度自地面（脚轮落地平面）起算；带脚轮时底架整体抬高一个轮径。
- 45° 为斜梯「底架 → 平台」的爬升角；水平段 = 爬升段，故 `run = (平台高 − 底架抬高) / tan(角度)`，平台落在最上一级踏步之后。
- 踏步按目标级高向上取整分级；`riser = 爬升段 / 级数`、`going = 水平段 / 级数`。非 45° 时级高与踏面不再相等。
- 立柱、底架、斜梁、平台框架均为矩形方管（实体块）；护栏、扶手、斜撑为圆管（圆柱）。构件之间**不做布尔相并**，允许重叠，仅作视觉连接。
- 前侧（梯口）不设护栏与踢脚板，便于上下平台。
- 不建模：脚轮转向机构 / 刹车、脚轮与底架间的连接板细节、链条/拉杆、焊缝、表面处理、铭牌。

## 使用方法

1. 在 OpenPlant Modeler 中打开一个**三维** DGN 模型。
2. 打开 Python Editor，运行 `maintenance_ladder.py`。
3. 在面板中设置平台高度 / 宽度 / 深度、爬梯角度、目标级高、护栏高，勾选是否加护栏、脚轮、斜撑；设置爬升方向水平角。
4. 在模型中**点取底架中心（地面）**，程序即时生成预览；改参数或再次点取自动重建一版。
5. 点【确定】保留预览；点【取消】删除本次预览。

生成结果按**两个普通单元**给出：**主体** `MAINTENANCE_LADDER`（立柱 + 底架 + 斜梁 + 踏步 + 平台 + 脚轮 + 斜撑）与**护栏** `MAINTENANCE_LADDER_GUARD`（平台护栏 + 斜梯扶手），可分别选中、隐藏或统计。参数变化时采用“先成功创建新版、再删除旧版”的方式重建。

## 几何规则

- 正交基 `n`（爬升，水平）、`t = z × n`（梯宽）、`z`（向上），满足 `n × t = z`。
- 派生几何：
  - `rise = 平台高 − 底架抬高`，`run = rise / tan(角度)`；
  - `总深 = run + 平台深`，`toe = −总深/2`，`平台前缘 = toe + run`，`平台后缘 = +总深/2`；
  - 斜梁中心线相对踏步鼻线沿斜面法向下移半个梁高，使斜梁顶面与踏步齐平。
- 踏步 `i`（1…级数）：踏面标高 `底架抬高 + i·riser`，水平范围 `[toe + (i−1)·going, toe + i·going]`；最上一级踏面标高 = 平台高。
- 平台护栏杆件：后侧沿 `t`、两侧沿 `n`，顶杆 `平台高 + 1000`、中杆 `平台高 + 500`。
- 斜梯扶手：沿斜面方向布置，杆件中心到斜面的垂直距离 = 扶手高；竖立柱高 = `扶手高 / cos(角度)`，其顶端正好落在斜扶手上。
- 斜撑为两端点圆管，`axis` 归一化为单位向量，长度 = 两端点距离。

## 已知限制（第一版）

- 不建模脚轮转向/刹车细节、连接螺栓、焊缝、制造圆角与切口。
- 护栏与平台、立柱与底架之间不做布尔并集。
- 不做栏杆门 / 活动梯口盖板。
- 平台花纹、踏步防滑纹以实体厚度近似，不建纹理。

## 调用方式

- 界面入口：`PyMain()`（脚本末尾有 `if __name__ == "__main__"`，在 Python Editor 中直接运行）。
- 编程调用：
  - `draw_maintenance_ladder(origin_point, outward=(1, 0), **params)`：直接生成并写入模型，返回单元句柄列表（主体、护栏）；`origin_point` 为底架中心的地面世界坐标 `DPoint3d`；
  - `build_maintenance_ladder_layout(**params)`：纯函数，返回毫米级构件布局（可在无 MicroStation 环境下测试）；
  - `compute_step_count(rise_mm, target_riser_mm)`：踏步级数；
  - `compute_stair_geometry(平台高, 平台宽, 平台深, 角度, 目标级高, 底架抬高)`：斜梯/平台派生几何；
  - `build_frame(outward)`：正交基 `(n, t, z)`。

## 几何自检

`_maintenance_ladder_selftest.py` 用 AST 抽取纯几何函数，**不需要 MicroStation**，任何 Python 3 都能跑：

```
python _maintenance_ladder_selftest.py
```

覆盖：正交基 `n × t = z`、踏步级数与最少 2 级、45° 斜梯派生几何（`run = rise`、平台前/后缘、中心）、默认布局（4 立柱高度、9 级踏步与最上级踏面 = 平台面、1000×1000×4 平台板、4 只 φ125 脚轮轮心离地 = 半径、4 根 φ20 斜撑）、平台顶杆标高 = 平台 + 1000、斜梯扶手到斜面的垂直距离 = 1000 / 500 与扶立柱数量、所有构件尺寸为正且轴向为单位向量（防斜撑漏归一化）、关脚轮时底架落地且 `run = 2000`、非 45° 时级高 ≠ 踏面、非法参数拒绝。全部通过时输出 `maintenance_ladder geometry self-test: OK`。

这是一份**几何建模**插件。若需要注册为带 Class / Tag / 规格属性的 OpenPlant 智能组件，还需结合项目使用的 OPM 类库、EC Schema 和目录规范。
