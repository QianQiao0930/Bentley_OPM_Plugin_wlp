# Bentley OpenPlant Modeler 安保围栏 Python 插件

`security_fence_body.py` 在 Bentley OpenPlant Modeler（基于 MicroStation 的 Python 环境）的活动三维模型中，沿用户点选的水平直线 / 折线 / 纯直线复杂链生成一道安保围栏（1.8 m 网片 + 450 mm 45° 防攀悬臂）。

整道围栏写成一个名为 `SECURITY_FENCE` 的**普通单元（Normal Cell）**，因此可以整体选中、移动、复制或删除。

## 几何规则

尺寸按 mm 解释，主要尺寸与 GS-M16《Specification for 1.83m Security Fence》对应：

| 构件 | 尺寸与位置 |
| --- | --- |
| 网片高度 | 1800（与柱顶悬臂起点齐平） |
| 防攀悬臂 | 长 450，与竖直方向成 45°，空心弯头中心线半径 R100 |
| 菱形网 | 网孔 64，网丝 φ2.5；按 ±45° 斜线在网片矩形内裁剪生成 |
| 张紧钢丝 | 4 道 φ4，标高 250 / 750 / 1250 / 1750 |
| 刺钢丝 | 3 道 φ2.5，沿悬臂直段按 1/3、2/3、3/3 布置 |
| 刺 | φ1.2、长 28 的 V 形短刺，沿刺钢丝每 500 一对 |
| 中间柱（细柱） | φ50 钢管、壁厚 4、管长 2400（地上 1800 + 埋深 600），间距 4 m |
| 转角 / 门 / 端 / 张紧柱（粗柱） | φ100 钢管、壁厚 4、管长 2600（地上 1800 + 埋深 800），间距 ≤ 50 m |
| 混凝土基础（可选） | 粗柱 400 × 400 × 600，细柱 300 × 300 × 450，顶面与地面齐平 |

**立柱布局规则（先粗柱、后细柱）**：

1. 先放**粗柱锚点**：路径起点、终点、所有折点（转角），以及相邻锚点间距超过 50 m 时按 50 m 补入的张紧柱。这些位置全部是 φ100 粗柱。
2. 每两个相邻粗柱之间是一个区间，把区间**等分成不超过 4 m 的若干跨**，在分点处放 φ50 细柱。
3. 细柱间距从每根粗柱 / 转角柱**重新起算**，因此不会出现“4 m 网格点正好落在转角柱旁边、两根柱子重叠”的情况；区间长度不是 4 m 整数倍时按等分处理，也不会留下 0.1 m 这种零碎末跨。
4. 由于折点一定是粗柱锚点，**任何一跨网片都不会跨越转角**，转角处的网片、张紧钢丝和刺钢丝都落在同一条直线上。

## 与 GS-M16 规范的对应关系

| 规范要求 | 本脚本 | 说明 |
| --- | --- | --- |
| 转角/门/张紧柱 φ100 × 2 mm，高 2.6 m | φ100、壁厚 4、管长 2600 | 管径一致；2.6 m 按**含埋深的管长**理解，地上仍是 1800 |
| 中间柱 φ50 × 2 mm，高 2.4 m | φ50、壁厚 4、管长 2400 | 同上，地上 1800 |
| 中间柱间距 ≤ 4 m | 每个粗柱区间内等分，跨距 ≤ 4 m | 一致 |
| 张紧柱间距 ≤ 50 m | 相邻粗柱锚点间距 ≤ 50 m | 一致 |
| 张紧柱基础 400 × 400 × 600 | 同 | 可选生成 |
| 中间柱基础 300 × 300 × 450 | 同 | 可选生成 |
| 网片 1.8 m + 450 mm 悬臂、菱形网 64 × 2.5、4 道 φ4 钢丝、3 道刺钢丝 | 同 | 一致 |
| 撑杆、Y 型标准件、大门、拉紧螺栓、蘑菇帽、底板、涂装、SANS 材料要求 | 未建模 | 本插件只做围栏主体的几何 |

两点需要留意：

- **壁厚**统一取 4 mm（规范写 2 mm），目的是让空心管的布尔运算和出图更稳定；如需严格按规范，把 `STEEL_TUBE_WALL` 改成 `2.0` 即可。
- **基础块深度**（600 / 450）小于柱子埋深（800 / 600），因此柱底会伸出基础底面 200 / 150 mm，与现场“柱脚伸入垫层以下”的做法一致。

## 使用方法（预览 → 调整 → 确定）

1. 在 OpenPlant Modeler 中打开或新建一个**三维**、公制的 DGN 模型。
2. 打开 **Utilities（实用工具）→ Python** 的 Python Editor。
3. 新建 Python Project，选择或复制 `security_fence_body.py`，然后执行。
4. 在模型中点选一条水平直线、折线或纯直线复杂链，围栏立即生成一版**预览**。
5. 看着模型里的预览调整面板选项，**改一次就自动重建一版**（旧的预览会被删掉，模型里始终只有一版）：
   - **防攀侧**：路径左侧 / 右侧，决定悬臂和刺丝朝向哪一边；
   - **反转路径方向**：会改变起点和粗柱里程（例如想让 50 m 粗柱从另一端起算时使用）；
   - **增加混凝土基础**：勾选后按上表尺寸生成 B 级混凝土块，取消勾选则只留钢管立柱（默认勾选）。
6. 觉得对了就点**【确定】**：当前这版预览就地保留，工具结束。
   点**【取消】**（或直接关掉面板、双击右键退出工具）则删除预览、放弃本次生成。
   想换一条路径直接再点选另一条线即可，旧预览会在新的一版建好后被替换掉。

面板会显示当前预览的统计（路径长度、折点数、粗柱/细柱根数、是否含基础、单元子元素总数），命令提示区同时输出同样信息。生成期间面板控件会临时禁用，避免重复触发。

脚本按活动模型的 `MASTER_UNITS_PER_METRE` 换算，输入始终按 mm 解释，不要求把主单位设成 mm。

## 实现说明

- **预览 / 确定机制**：生成分两步——`_build_security_fence_cell()` 在内存里把整道围栏建完（**不写模型**），成功后 `commit()` 才 `AddToModel()`；`replace_security_fence()` 负责“先建新的一版、写进模型，再删掉上一版预览”。因此**新的一版构建失败时旧预览不会被删**，改选项不会把模型里的围栏改没了。面板上保存着最近一次点选的路径顶点和当前预览的 `EditElementHandle`，改选项时用它们重建；删除前先 `IsValid()` 判断句柄是否还有效（用户手动删掉或按了 Ctrl+Z 的情况）。
- **单元封装**：`_FenceCellBuilder` 先创建孤立单元头，逐个 `AddChildElement`，最后 `AddChildComplete`；任何一步失败就整体放弃，不会在模型里留下半成品。
- **空心钢管**：外圆柱减内圆柱；内圆柱两端各外伸 2 mm，避免端面共面导致布尔减法失败。
- **空心弯头**：`DgnTorusPipe` 圆环管做同样的布尔减法。内弧的向量基是把外弧向量基绕弯头所在平面的法向 `(-ny, nx, 0)` 旋转 `2 mm / R` 得到（见 `_elbow_inner_frame`），因此无论路径走向和防攀侧如何，内外弧始终共面，任意方向都能正确掏空。
- **混凝土基础**：先按底面四点创建矩形 Shape，再用 `SolidUtil.Modify.ThickenSheet` 沿 +Z 拉伸成实体，因此轮廓画在 `-depth` 处、拉伸 `depth` 后得到顶面齐平的块体。
- **路径校验**：只接受非闭合、纯直线（Line / Line String / 纯直线 Complex String）、高程差 ≤ 1 mm、无自交且段段连续的路径；圆弧路径、闭合路径、自交路径都会在点选时被拒绝并给出原因。
- **立柱定位**：以路径累计里程（station）计算。先按“起点 / 终点 / 折点 / 每 ≤50 m”生成粗柱锚点，再在相邻粗柱之间把区间等分成 ≤4 m 的跨距、在分点放细柱（`_build_post_layout`）；折点处取相邻两段法向的角平分方向作为防攀侧方向。

## 已知限制

- 只支持**水平**路径（高程差超过 1 mm 会报错），不支持带坡度的围栏。
- 不支持圆弧段路径；需要圆弧时请先拆成折线。
- 不生成撑杆、Y 型标准件、大门、拉紧螺栓、蘑菇帽、底板和涂装；这些构件如需建模需另行扩展。
- 长路径的单元子元素数量较大（4 m 跨约 180 条网片斜线，8 m 跨约 310 条，另加刺和立柱实体），模型显示与保存会变慢。

## 调用方式

- 界面入口：`PyMain()`（脚本末尾有 `if __name__ == "__main__"`，在 Python Editor 中直接运行即可）。
- 编程调用：
  - `draw_security_fence_along_path(vertices, side="left", reverse=False, include_foundation=True)`：直接生成并写入模型，`vertices` 为 `DPoint3d` 列表，返回统计字典；
  - `replace_security_fence(vertices, side, reverse, include_foundation, previous_handle)`：预览用的重建接口，返回 `(新单元句柄, 统计字典, 是否删掉旧预览)`；
  - `draw_security_fence(total_length, placement_point, include_foundation)`：兼容旧接口的直线版本。

这是一份**几何建模**插件，创建的是活动 OPM 模型中的 MicroStation SmartSolid 图元。若需要把它注册为带 Class / Tag / 规格属性的 OpenPlant 智能组件，还需结合项目使用的 OPM 类库、EC Schema 和目录规范。
