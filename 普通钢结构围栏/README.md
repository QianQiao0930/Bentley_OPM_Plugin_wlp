# 普通钢结构围栏插件（第一版）

`steel_handrail.py` 在 Bentley OpenPlant Modeler / MicroStation 的活动 3D 模型中，沿用户点选的水平或带坡度智能线创建普通钢结构围栏。整道围栏封装为名为 `STEEL_HANDRAIL` 的普通单元。

## 第一版构件

| 构件 | 尺寸或规则 |
| --- | --- |
| 立柱 | φ48.3×3.2 空心钢管 |
| 顶部扶手 | φ42.4×3.2 空心钢管，中心标高 1017 mm |
| 中间横杆 | φ33.7×3.2 空心钢管，中心标高 560 mm |
| 连接球 | 立柱与两道横杆交点各一个，直径 76 mm |
| 踢脚板 | 130×6 mm，位于所选内侧，底边高于安装面 10 mm；沿完整偏移路径连续扫掠 |
| 踢脚板支架 | 每根立柱一块短连接板；踢脚板与立柱外圆净距 10 mm |
| 立柱连接形式 | UI 下拉选择类型1～4；当前仅类型2生成几何，其余类型为预留 |
| 类型2底部节点 | 立柱向内侧以 R76 下弯，水平管中心标高 -76 mm；管端设置 146×75×10 mm 连接板，板中心与管中心对齐，146 mm 长边平行于路径三维切向 |
| 立柱排布 | 按三维实际路径长度计；相邻立柱不超过 2000 mm，各控制区间按 50 mm 工程模数优先圆整，余量优先放在首尾跨，不足 50 mm 的尾数最多保留在一跨 |
| 转角 | 横杆中心线 R140；转角两侧优先在距理论折点 300 mm 处设柱 |
| 端部闭合 | 可选；160 mm 水平直段 + R140 弯头 + 177 mm 竖直段 + R140 弯头；坡段端部按路径切线的水平投影生成，并采用端点局部标高 |
| 颜色 | 精确 RGB (255, 204, 0) |

当前稳妥版接受非闭合、无自交的水平段和单一坡度直线段。立柱始终竖直，横杆、踢脚板和底部连接节点的标高均相对路径局部标高计算；纯变坡点保留尖折并强制设置立柱。水平转向折点自动转换为 R140 圆角；同一折点如果既转向又涉及坡度则明确拒绝，以免生成不可控的空间弯头。暂不支持竖直段、闭合路径，以及底板、角钢、螺栓和支撑钢梁等安装节点。

踢脚板不是由短直板拼接，而是先计算与栏杆直线及 R140 转角严格相切的内侧偏移路径，再用 130×6 mm 闭合矩形截面执行一次 `SolidUtil.Create.BodyFromSweep` 连续扫掠。转角的实际踢脚板中心半径会根据内外侧自动增减偏移距离。

## 使用方法

1. 在 OpenPlant Modeler 中打开 3D DGN 模型。
2. 打开 Python Editor，运行 `steel_handrail.py`。
3. 点选一条水平或带单一坡度的智能线，程序立即生成预览。
4. 在工具设置中选择踢脚板位于路径左侧或右侧，并可选择反转路径、生成两端闭合回弯。
5. 在“立柱连接形式”中选择类型2，并填写“立柱中心至连接板”距离；默认值为 250 mm。
6. 点击“确定”保留预览；点击“取消”删除本次预览。

界面选项变化时采用“先成功创建新版、再删除旧版”的方式重建，因此几何创建失败不会误删上一版有效预览。
