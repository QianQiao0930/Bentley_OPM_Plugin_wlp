# 普通钢结构围栏插件（第一版）

`steel_handrail.py` 在 Bentley OpenPlant Modeler / MicroStation 的活动 3D 模型中，沿用户点选的水平或带坡度智能线创建普通钢结构围栏。整道围栏封装为名为 `STEEL_HANDRAIL` 的普通单元。

## 第一版构件

| 构件 | 尺寸或规则 |
| --- | --- |
| 立柱 | φ48.3×3.2 空心钢管 |
| 顶部扶手 | φ42.4×3.2 空心钢管，中心标高 1017 mm |
| 中间横杆 | φ33.7×3.2 空心钢管，中心标高 560 mm |
| 连接球 | 立柱与两道横杆交点各一个，直径 76 mm |
| 踢脚板 | 130×6 mm，位于所选内侧，底边高于安装面 10 mm；沿完整偏移路径连续扫掠 |
| 踢脚板支架 | 每根立柱一块短连接板；踢脚板与立柱外圆净距 10 mm |
| 立柱连接形式 | UI 下拉选择类型1～4；类型1、类型2、类型3生成几何，类型4为预留 |
| 类型3底部节点 | 145×75×10 mm 水平底板，底面位于路径局部安装标高，145 mm 长边沿路径水平投影；圆管立柱位于底板中心，从板顶（安装标高 +10 mm）竖直向上。坡段底板仍水平。扶手和横杆标高仍相对安装面计算；不生成孔、螺栓或支撑钢梁 |
| 类型1底部节点 | 立柱在安装面处由 Φ48.3 圆截面直纹放样至椭圆压扁端，再以椭圆截面延伸至连接板下缘。椭圆短轴为钢管原外径的 1/3，即 16.1 mm；长轴暂定 70 mm、过渡长度 38.5 mm；长轴沿路径水平切向。压扁过程中截面中心向板侧移动，靠板侧外轮廓始终与 146×75×10 mm 连接板近面相切。板中心标高 -76 mm，水平段管底标高 -113.5 mm；板长边跟随路径三维切向。不生成螺栓、支撑钢梁或焊缝实体 |
| 类型2底部节点 | 立柱向内侧以 R76 下弯，水平管中心标高 -76 mm；管端设置 146×75×10 mm 连接板，板中心与管中心对齐，146 mm 长边平行于路径三维切向 |
| 立柱排布 | 按三维实际路径长度计；相邻立柱不超过 2000 mm，各控制区间按 50 mm 工程模数优先圆整，余量优先放在首尾跨，不足 50 mm 的尾数最多保留在一跨 |
| 转角 | 横杆中心线 R140；转角两侧优先在距理论折点 300 mm 处设柱 |
| 端部闭合 | 四选一：不闭合 / 仅始端 / 仅末端 / 两端；每端为 160 mm 水平直段 + R140 弯头 + 177 mm 竖直段 + R140 弯头；坡段端部按路径切线的水平投影生成，并采用端点局部标高 |
| 颜色 | 精确 RGB (255, 204, 0) |

当前稳妥版接受非闭合、无自交的水平段和单一坡度直线段。立柱始终竖直，横杆、踢脚板和底部连接节点的标高均相对路径局部标高计算；纯变坡点保留尖折并强制设置立柱。水平转向折点自动转换为 R140 圆角；同一折点如果既转向又涉及坡度则明确拒绝，以免生成不可控的空间弯头。暂不支持竖直段、闭合路径，以及角钢、螺栓和支撑钢梁等安装节点。

踢脚板不是由短直板拼接，而是先计算与栏杆直线及 R140 转角严格相切的内侧偏移路径，再用 130×6 mm 闭合矩形截面执行一次 `SolidUtil.Create.BodyFromSweep` 连续扫掠。转角的实际踢脚板中心半径会根据内外侧自动增减偏移距离。

## 钢材清单（ItemType + JSON）

生成围栏时给每个钢构件类型挂一个 **ItemType 构件项**（属性 `ComponentName`、`Specification`、`DesignLengthMm`、`Quantity`、`Unit`），定义写入 DGN 的 `SteelHandrailComponents` 库；面板上的 **【导出 JSON 清单】** 调用 `export_steel_handrail_bom_json()`，扫描当前 DGN 按 `名称 + 规格 + 单位` 汇总数量与总长。

| 构件 | 规格 | 长度口径 |
| --- | --- | --- |
| 顶部扶手 | 钢管 φ42.4×3.2 | 各段中心线实长 |
| 中间横杆 | 钢管 φ33.7×3.2 | 各段中心线实长 |
| 立柱 | 钢管 φ48.3×3.2 | 类型3 为 1007；类型1/2 为 1017；× 根数 |
| **连接球** | 实心球 φ76 | **按件计：每根立柱上、下横杆交点各 1 个，共 根数×2** |
| 踢脚板 | 钢板 130×6 | 路径实长 |
| 踢脚板支架 | 钢板 6×50 | 每根立柱 1 块 |
| 底部连接板 | 类型1/2 钢板 146×75×10；类型3 钢板 145×75×10 | 每根立柱 1 块 |
| 压扁端 | 钢管 φ48.3×3.2 | 类型1 每柱（水平路径代表值 113.5） |
| 立柱下弯段 | 钢管 φ48.3×3.2 | 类型2 每柱（R76 弯头弧长 + 水平段） |
| 端部闭合回弯 | 钢管 φ42.4×3.2 | 每个闭合端 1 组（160×2 + 竖直段 + 2×R140 弧长） |

管类按中心线长度计；球 / 板 / 支架按件计（`DesignLengthMm` 记代表性长度或 0）。压扁端与类型2下弯段在坡段上的长度为近似值。

## 使用方法

类型1的压扁端尺寸由 `TYPE1_FLAT_MAJOR`、`TYPE1_FLAT_MINOR`、`TYPE1_TRANSITION_LENGTH` 控制，短轴按钢管原外径的 1/3 计算，长轴和过渡长度为待详图确认的建模默认值。外形使用解析圆/椭圆截面放样；内腔以截面半轴减去 3.2 mm 壁厚后放样并布尔扣除，属于空心外观近似，不代表压扁加工后的精确等壁厚或材料守恒形状。放样或布尔扣除失败时明确报错，保留上一版有效预览。

1. 在 OpenPlant Modeler 中打开 3D DGN 模型。
2. 打开 Python Editor，运行 `steel_handrail.py`。
3. 点选一条水平或带单一坡度的智能线，程序立即生成预览。
4. 在工具设置中选择踢脚板位于路径左侧或右侧，可勾选反转路径方向；"端部闭合回弯"可选 不闭合 / 仅始端 / 仅末端 / 两端。
5. 在“立柱连接形式”中选择类型1（直柱贴板侧装）、类型2（侧装钢结构）或类型3（底板顶装）。类型1按钢管与板面相切定位，无需填写距离；类型2可填写“立柱中心至连接板”距离，默认值为 250 mm。这两种类型的连接板均朝向所选内侧。类型3底板居中，无需填写连接距离。
6. 点击“确定”保留预览；点击“取消”删除本次预览。
7. 点击“导出 JSON 清单”按规格汇总当前模型内的围栏钢材（含连接球个数），写出 `普通钢结构围栏_bom.json`。

界面选项变化时采用“先成功创建新版、再删除旧版”的方式重建，因此几何创建失败不会误删上一版有效预览。
