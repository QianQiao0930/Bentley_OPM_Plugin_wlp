# 单根水平圆弧

新增单根非闭合水平圆形圆弧，保留真实圆弧，支持左右侧、反向、四种连接形式。按偏移后弧长排柱，立柱竖直，板件随局部切向旋转。

偏移后围栏和踢脚板中心半径至少 140 mm（建模下限，不代表工程规范），另检查节点间距及端部回弯净距。拒绝整圆、椭圆、倾斜圆弧、近整圈节点重叠。**混合复杂链自 2026-10-06 起已支持**（直线 + 水平圆弧 + 固定半径/螺距螺旋的非闭合链，按原生曲线求值采样，见主 README「普通钢结构围栏」节与 `MixedPathChecks.cs` 的 64 组检查）；本文只描述“单根圆弧”这一条独立分支。

离线验证覆盖 48 组圆弧组合及原有直线路径。需要在 OPM 副本模型中验证顺逆时针圆弧、长圆弧、左右侧、参数更新、取消与确认，检查真圆弧实体及踢脚板扫掠，无部署操作。
