# A1 原生关联离线检查

运行：`dotnet run --project Development/A1NativeSupportCheck/A1NativeSupportCheck.csproj -c Release`

检查直接链接生产环境中的试验适配器、JSON ItemType 存储、站位计算和 A1 目录/计算。DGN、EC、原生对象和事务采用 API 替身；生产环境的 unsafe 图形桥接由主工程对真实 OPM SDK 编译验证。链接的领域模型有其他模块专用字段，本检查工程单独忽略 CS0649，不影响主工程警告设置。

覆盖三个 UOR 比例、四个水平管方向和三个开口角度，验证父关系、对象标识、模型记录、原材料清单、缓存所有权；检测管动夹未动、外形被参数化替换、错误父管、复制件和撤销删除；注入创建、序列化、缓存、清单、元数据、关系、坐标和图形类型故障，核对回滚及回滚失败的不同处理。

原生API替身从临时实例ID `mechanical` 开始；延迟提交开启时模拟Create成功但不生成模型元素，立即提交时才生成持久ID。宿主默认开启延迟提交的用例要求真实适配器创建成功并恢复开关；失败也必须恢复原开关。

第二轮宿主数据证明非参数化A1的GetSectionalDataForSupport未计算支点。替身现保留零支点，不再替生产代码自动补正确坐标。真实适配器必须显式写Design/SHOP，使用SDK毫米转换方法写入XYZ，保存并重读检查；覆盖3种模型UOR比例×3种Schema坐标单位（毫米/英寸/米）×4个管向×3种开口角。三维跟随但ISO支点未跟随必须失败，CHECK不得偷偷修正；还覆盖非零标高、真实原点、缺失/非有限坐标、空/既有/拆除状态、坐标写失败/序列化丢失、状态丢失、Schema缺字段。当前合计1816项。

这些检查不执行 Bentley 内核、ISO 提取器和实际宿主移动行为。完整试放步骤见 [A1原生关联试验](../../Docs/A1原生关联试验.md)。
