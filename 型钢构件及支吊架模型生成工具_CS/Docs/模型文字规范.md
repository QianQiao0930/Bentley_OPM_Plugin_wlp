# 模型文字统一规范

生效日期：2026-10-13。按用户要求，适用于本 C# 工程全部写入 DGN 模型的文字，以及今后新增功能中的文字。灭火器箱、轻便消防水龙柜、今后的消火栓箱、设备铭牌、构件名称等均须遵守。

## 强制实现

所有模型文字必须通过 `Services/ModelTextFactory.cs` 的 `ModelTextFactory.Create` 创建。现有灭火器箱和水龙柜通过 `FireCabinetBuilder.Text` 的布局适配方法调用该工厂。新模块直接复用公共工厂，不复制一份原生文字创建逻辑。

1. 字高、字宽由构件实际尺寸决定，使用毫米。进入 Bentley 边界后，按模型 `UOR/mm` 换算一次。不得乘绘图比例、注释比例或活动放置比例，也不得先除当前比例来补偿。
2. 使用普通、可编辑的文字对象。创建前清除 `TextBlockProperties` 的持久文字样式及注释比例关联，设置 `IsViewIndependent=false`；`RunProperties` 同样清除持久样式关联，最后显式设置字号。
3. 字体可由明确选定的字体或工厂当前默认 TrueType 字体提供；字号不跟随全局文字样式。中文缺字、字体替换属于独立问题，需另行检查。
4. 位置和方向随构件局部坐标确定。原点使用模型 UOR；旋转矩阵使用单位轴，不含单位缩放。文字颜色、内容及排版由调用模块提供，保留其设计意图。
5. 创建后检查元素是否带有注释比例，发现残留必须报错并阻止确认，不静默生成比例异常的文字。禁止对这类文字或所属组合调用 `AddAnnotationScale`，所属组合须为普通 Cell。
6. 工厂只返回离线元素，不直接写入模型。调用模块将文字与其他构件一起交给原有预览/确认会话管理；取消、退出及关闭时随预览清理，确认后保留。
7. 禁止修改模型绘图比例、全局文字样式、注释比例锁或活动放置参数来实现固定字高；禁止自动批量改写用户已有文字或模型。

这条规范只约束 DGN 中的模型文字。WPF 界面标题、参数提示、Excel/JSON/Markdown 文本不属于模型文字。

## 调用示例

```csharp
Element label = ModelTextFactory.Create(
    model,
    "消火栓箱",
    originUor,
    localRotation,
    heightMm: 30,
    uorPerMm: model.GetModelInfo().UorPerMeter / 1000.0,
    color: labelColor);
// 将 label 加入本模块的预览组合，不在此直接 AddToModel。
```

示例中的 30 mm 仅演示接口；实际字高必须根据具体构件和可用版面确定。不得把该数值作为所有设备的固定默认值。

## 验证与维护

- 修改或新增模型文字后，运行 `python Development/check_model_text.py`。此只读检查扫描运行时代码，禁止在工厂外创建原生文字或添加注释比例，并检查工厂中的固定尺寸操作仍存在。
- 编译授权及无授权版本，并运行受影响模块的尺寸、配置与统计回归。
- OPM 中分别在不同注释比例（例如 1:1、1:50、1:100）下生成模型，随后切换比例，确认文字相对构件的大小、位置和方向一致。保留实际模型毫米字高，而非固定屏幕像素大小。
- 检查正面、顶面、旋转、预览替换、确认、取消及返回首页。离线源码检查及编译不能代替 Bentley 宿主显示验证。
- 本规范作用于新生成的 C# 模型。已有模型需重新生成才能应用；当前工程中的规范不自动改写同级独立 Python 插件。

## 当前覆盖

当前 C# 项目的原生模型文字入口已集中到 `ModelTextFactory`：灭火器箱的四处标识、轻便消防水龙柜的两处标识。当前功能清单没有独立的消火栓箱模块；新增该模块时，文字必须按本规范创建。
