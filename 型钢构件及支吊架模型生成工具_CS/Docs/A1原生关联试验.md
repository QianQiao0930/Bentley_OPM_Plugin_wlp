# A1 原生支吊架关联试验

本轮验证两个问题：A1 以 OpenPlant 支吊架身份生成后，能否进入单线图；与管道建立原生关系后，能否由宿主随管道一起移动。宿主第二轮已确认能够落模、建立父管关系并提取U形符号，但ISO支点误在原点、无材料表和编号标注；不能据此认定出图或跟随全部成功。本版已修复出图点和设计状态，离线检查通过，需重新放置、提取ISO和测试移动。

2026-10-14 第二轮数据依据：创建日志显示三维误差0mm；实际L00中A1为 `CT_SUPPORT` / `SUPP_UBOLT@90`，`IE_TAG=A1TEST-0002`、描述存在，但 `SUPPORT_POINT_X/Y/Z=0`、`IE_EXISTING=1`，且STATE为空。活动工作集的IE_EXISTING表达式将空状态视为既有件；SHP报告仅含管道与弯头。当前修复在GetSectionalDataForSupport之后显式设置STATE=Design、SHOP_FIELD=SHOP，并用BMECObject.SetDoubleValueFromMM写入目标站位XYZ，再序列化、重新读取校验。Schema长度单位不与DGN UOR混用，不修改项目提取规则或标注样式；实际材料表与编号显示仍以复试为准。

2026-10-14 首轮宿主反馈：`Create`/`Serialize` 返回成功后，实例仍是临时ID `mechanical`，读取图形元素失败，事务已报告回滚；还未进入ISO/随动测试。旧代码遗漏 `DeferCommits` 保护，本机SDK的Create在该开关为true时只排队。现复用管道编辑的立即提交规则：仅在本次创建范围临时设false，成功或失败都恢复原值，不提交全局待处理集合；增加持久ID校验及创建/序列化/元素阶段日志。旧日志未记录开关原值，仍须重试确认修复是否解决宿主失败；新日志同时记录实际加载DLL路径与模块标识，便于排除加载了旧版。

## 操作步骤

1. 使用测试 DGN，加载本次构建的 `SteelSectionProbe.dll`。如果之前已加载旧 DLL，先重启 OPM。结束其他放置工具，再用元素选择工具选中**一根活动三维模型中的 OpenPlant 水平裸直管**。建议从 DN100、外径 114.3 mm 开始。
   本次修复作用于新PLACE创建的对象。请先删除测试模型中的旧试验A1，再重新放置，避免重叠、重复统计；CHECK保持只读，不自动修复旧件。
2. 在 Bentley 的 Key-in 中输入 `STEELPROBE A1TEST PLACE`。默认在管轴中点生成一个试验 A1，开口角度为 0°，可用 Undo 撤销。需要指定位置时输入 `STEELPROBE A1TEST PLACE 500 90`，表示距管轴数据起点 500 mm、开口角度 90°；起点按原生管轴端点顺序，不是鼠标选择端。
3. 选中生成的 A1，输入 `STEELPROBE A1TEST CHECK`，再输入 `STEELPROBE A1TEST LOG` 查看日志。初始状态应关系通过、三维和ISO支撑点两处位置误差均不超过1mm、STATE=Design、SHOP_FIELD=SHOP、图形为自定义非参数化外形。目视核对 U 形螺杆和四颗螺母是否完整、开口方向是否正确。
4. 用项目平常的 ISO 提取流程对这根管道所属管线出单线图，检查支吊架符号、位置、数量和材料信息。输出符号遵从当前工作集规则，不等于把三维五个子件逐个投影到图纸；现有插件材料清单与 ISO 材料表也需分别核对。
5. **只选择管道**，使用实际生产中的原生移动命令平移一段距离。选试验 A1 后再次 `CHECK`，核对误差和外形；再分别测试管道水平旋转、Undo/Redo、保存关闭重开后检查。每种操作单独记录结果，不能仅凭初次创建成功认定跟随有效。

`LOG` 打开 `%LOCALAPPDATA%\SteelSectionProbe\logs\A1NativeSupport\latest.log`，每次 PLACE/CHECK 覆盖上一次日志；需要对比时先另存。若出错，日志包含异常、试验标签及已获取的元素/实例标识。失败尝试回滚本次事务；若明确报告“回滚未完成”，应按日志标识检查测试模型中的残留对象。

## 范围与实现

- 此入口独立于原 A1 页面，原页面仍按原流程生成普通 Cell。既有管夹不自动转换，首页没有新增模块；仅 `A1TEST PLACE` 生成本次试验对象。
- 仅接受单根、活动模型、可写、无保温、外径与 A1 表一致的原生 `PIPE`，且必须可靠读取水平直管轴。参考模型、辅助线、弯头、斜管、未知 DN 等明确拒绝。首轮只考察刚体平移及水平旋转；伸缩、改径、切管、换管、复制、删除关系的行为不作保证。
- 复用 `A1ClampCalculator`、目录和 `A1ClampBuilder` 的真半圆螺杆及螺母，离线组为 Cell，再交给 `BMECObject(instance, true)` / `SetNonParametricElement` / `Create` / `BMECObjectWriter.Serialize` 创建非参数化 `UBOLT_GUIDE`。`RelatedInstance` 指向所选管道，创建后反查 `DEVICE_HAS_SUPPORT`，必须且只能找到该管道。
- 原材料清单继续调用 `Statistics.AttachA1Clamp`，原九字段契约不变。试验参数单独存放在 `SteelSectionProbeTrials/A1NativeSupport` 的 JSON Payload，记录父管道/支吊架实例、站位、角度、DN 和原管长；CHECK 拒绝复制后身份不匹配的记录。
- 原生创建期间临时关闭 `BMECApi.DeferCommits`，finally恢复；不调用 `CommitDeferedChangeSet`。创建完成必须具有持久实例ID，不能把API返回成功等同于已经写入DGN。
- CHECK重新读取当前管轴和原生支吊架对象，比较原始站位对应位置与当前变换原点、按Schema单位转换成毫米的SUPPORT_POINT，容差各1mm；同时检查Design/SHOP和非参数化图形类型。三维跟随而ISO支点不跟随必须报告不通过。真正站位在原点时允许零值，空坐标/非有限值明确失败。日志通过仅表示这些数据校验通过；旋转姿态、实体外形、ISO 输出需实际核对。本轮没有增加事件监听或插件补偿移动，便于判断原生关系本身是否能完成跟随。
- 不改工作集 Schema、ISO 样式、管道几何或全局布局。当前本机工作集样例 Schema 的 `UBOLT_GUIDE` 继承 `SUPPORT`，通过 `DEVICE_HAS_SUPPORT` 关联 DEVICE；Isoextractor 补充 Schema 的符号为 `SUPP_UBOLT@90`。实际活动工作集可能不同，需以真实提取结果为准。

## 如何判断下一步

| 实际结果 | 后续方向 |
| --- | --- |
| 可出图、可跟随且外形保留 | 再接入 A1 正常界面，扩展斜管、参数编辑与其他支架 |
| 可出图、移动后不跟随 | 保留原生支吊架身份，另做管道变更驱动的关联更新和 Undo 配套 |
| 可跟随、外形被重生成 | 调整非参数化组件生命周期，或采用原生参数化支架和 A1 自定义图形的组合 |
| 有关系但不出图 | 检查活动工作集提取规则、SUPPORT_POINT、管线归属及 ISO 日志，再决定是否需要项目配置 |
| 原生创建失败 | 根据最新日志确认 SDK/工作集必要属性或创建顺序，修正后重试 |
