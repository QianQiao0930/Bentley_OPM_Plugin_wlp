# 立管耳轴、弯头耳轴原生接入（自带类 + 操作柄）

立管 F6/F7/F10 及弯头 F2/F2-HE/F4/F5 确认后落 OPM 自带类，复用 `SUPP_TRUNNION` / `SUPP_ELBOW` 图例。同时以参数化 `NativePipeSupportComponent` 挂自定义 Builder，从而保留原生滑动/旋转操作柄（立管）与随父构件移动。

## 类映射

| 类别 | 自带 EC 类 | ISO 图符 | 手动操作柄 |
| --- | --- | --- | --- |
| F6 / F10 | `SINGLE_PIPE_TRUNNION` | `SUPP_TRUNNION` | 开（沿轴滑动 / 旋转） |
| F7 | `DOUBLE_PIPE_TRUNNION` | `SUPP_TRUNNION` | 开 |
| F2 / F2-HE / F4 / F5 | `SIMPLE_ELBOW_SUPPORT` | `SUPP_ELBOW` | 关（仍随弯头移动） |

完整配方写入实例属性 `SSP_RECIPE`（版本1 Vertical/Elbow）。`ALIAS` 为原材料编号；部署脚本将三类 `IE_TAG` 设为 `this.ALIAS`，并保留原 `ClassMap`。Modeling 三类 `CREATION_ATTRIBUTE` 指向本插件 `NativePipeSupportComponent`（否则非参数化落模没有操作柄）。

立管坐标架对齐自带 SinglePipeTrunnion：局部 X=管轴（点串 direction=−X，滑动沿管），局部 −Z=方位角伸出（圆柱与 LENGTH 都在 −Z，旋转柄才在耳轴端；F6/F7 的 0°=+Y）。不得把 Z 设成管轴，否则旋转柄落到立管上。点串与自带类相同，为 (−X, +Z)。管夹仍用管夹架（X=管轴，Z=向上）。

`NativePipeSupportComponent.Setup` 在构造期若读不到 `SSP_RECIPE`（旧件或无配方实例）只跳过，不弹 FATAL；真正 `Create3DElements`/`PrepareGraphics` 时仍要求完整配方。旧无配方自带类件请删除后用本插件重放。

辅助线、参考、HVAC 弯头仍普通 Cell。旧 `SSP_TRUNNION` / 非参数化自带类件不自动迁移，需重新放置。

## 安装

关闭 OPM 后：

```text
Deployment/Install-NativeSupportEditing.ps1 -Features Trunnion -SchemaDirectory '<Schemas>' -BackupDirectory '<备份>' -Apply
```

会写入：基础类 `SSP_RECIPE`、Modeling 参数化组件、Isoextractor `IE_TAG=ALIAS`。重启 OPM 后**新放**耳轴才会有操作柄；仅换 DLL 不够。

与正式管夹一起部署时省略 `-Features`（默认 `All`，一次写入耳轴三类与 `SSP_PIPE_CLAMP`）。这是唯一的安装实现，共用一份备份/替换/回滚逻辑，重复运行幂等。

## 验收

立管选中后应出现滑动/旋转柄；弯头耳轴不应出现这两类柄，但移动弯头时耳轴与 ISO 点跟随。ISO 为耳轴图符且引注等于原材料编号。
