# 放置管夹：原生支吊架与轴测图接入

## 当前用法

重启OPM加载本次DLL，在首页进入“放置管夹”，按原流程点取管道、调整方向/沿轴位置、更新预览、确定生成。选中**活动三维模型中的可写原生PIPE直管**时，九类构件确认后都会成为有父管关系的原生支吊架，可用项目原有ISO提取流程出图，无需执行A1TEST命令。预览阶段不附加业务关系或材料记录。

| 类别 | ISO描述 | 标注中的关键参数 |
| --- | --- | --- |
| A1 | U-BOLT CLAMP | DN、M螺杆直径、ANG开口角 |
| U3 | BEARING U-BOLT | DN、A/G子项、C1/S/S1材料、M |
| A2 | STANDARD 2-BOLT CLAMP | DN、B保温厚度、M |
| A22 | COLD 2-BOLT CLAMP | DN、B保冷厚度、M |
| A24 | COLD 4-BOLT CLAMP | DN、B保冷厚度、M |
| E1 | PIPE GUIDE | DN、目录子项、型钢规格、H |
| K1 | PIPE STOP | DN、子项、W已有钢构宽度 |
| T4 | HOT INSULATED SHOE | DN、L管托长度、B隔热厚度 |
| L2 | COLD PIPE SHOE | DN、L管托长度、B保冷厚度 |

尺寸单位mm、角度单位度。标注示例 `A24-DN100-B40-M12-0001`；末尾编号由当前工作集命名规则管理，不保证从0001开始。当前ISO种子不能正确显示中文，因此ISO名称和描述使用ASCII代号与英文，原插件中文分类、规格、材料明细的九字段契约不变。

九类统一使用原生 `SUPPORT_LOCATION`（支架位置）类，继承SUPPORT的ISO提取规则，经 `ClassMap(...,"SUPP")` 使用工作集的通用简图，即支架位置类简化符号，不再把所有类别伪装成UBOLT_GUIDE。当前本机Schema的Support Tag Labels读取NAME，材料报告已有Supports分组；不修改全局Schema、符号库、ISO样式或已出图DGN。实际双横线外观、尺寸、材料表、编号需在当前样式重提ISO核对。

辅助线和参考来源保持普通Cell与本地材料清单，页面明确提示不建立ISO关联；参考管轴物化的临时线不能冒充活动管道。已经生成的普通Cell/旧试验件不批量转换，需新放置。真实管道身份不明、被删/锁定、模型或单位变化、预览后管轴/管径/外径/保温变化、定位超出管轴段时拒绝确认，避免关联到错误对象。

本轮提供原生父管关系和ISO数据，不增加自动跟随监听。移动后支吊架是否跟随、ISO支撑点是否同步、保存重开和Undo/Redo，仍须单独实测；不能仅凭关联存在认定这些行为都已实现。

日志：`%LOCALAPPDATA%\SteelSectionProbe\logs\NativePipeSupport\latest.log`，每次原生确认覆盖，含实际DLL/MVID、类别/规格、父管、目标点、原生元素、编号及异常。A1TEST仍保留自己的日志入口。

## A1试验已经确认的事实

用户在2026-10-14的实测图片与实际L00/SHP报告已确认：A1可保留自定义三维外形，建立DEVICE_HAS_SUPPORT关系，正确定位ISO符号，生成编号和材料表。试验过程暴露的三个问题必须作为后续接入约束保留：

1. `BMECApi.DeferCommits=true` 时Create/Serialize可以返回成功但只排队，ID仍是 `mechanical`。本次新建范围临时设false，finally恢复；不得提交或清空全局DeferedChangeSet。
2. 自定义非参数化几何的 `GetSectionalDataForSupport` 未自动计算SUPPORT_POINT。三维变换正确不代表ISO位置正确，必须调用 `SetDoubleValueFromMM` 写目标轴点XYZ，序列化后按Schema单位读回；不将UOR直接写入EC字段。
3. STATE空值在当前项目映射成IE_EXISTING=1，表现为虚线、无材料表。新构件显式Design/SHOP，保存后校验；不要为修一个构件改全局“既有件”提取规则。

A1的成功不能替代新SUPPORT_LOCATION类、全部九种实体和正式页面暂态预览在OPM中的验证。

## 共用接入接口

- `OpenPlant/NativePipeSupport/NativeSupportGraphics.cs`：固定原生EditElementHandle，SetNonParametricElement、Create、设置变换、Serialize；句柄及离线图形存活到全部回调序列化结束。SetNonParametricElement会提取离线图形描述，不能拿正式模型元素直接传入。
- `NativeSupportData`：Design/SHOP、按mm写/读SUPPORT_POINT；反查唯一DEVICE_HAS_SUPPORT、三维和ISO各1mm容差、非参数化外形。只校验数据，不暗中移动对象。
- `NativePipeSupportWriter.Create`：授权/Undo保护，独立宿主事务、立即提交、缓存所有权、附加材料/记录、持久对象重读验证，最后释放暂态预览。失败回滚；回滚失败明确报错并保留缓存或包装对象所有权。
- `NativePipeSupportSource`：用点取时的原生实例ID、元素ID、模型指针标识、单位、轴段和管径快照重新确认父管；构建沿轴的正交坐标架及逆变换。正式几何用当前真实计划重建，先逆变换为局部，再由原生变换放回，防止重复平移/旋转，支持各类别原有的水平/斜管/立管范围。
- `NativePipeSupportDefinition`：九类ASCII标注和原生类选择。`SUPPORT_LOCATION.NOMINAL_DIAMETER` 在本机Modeling补充Schema为string，必须检查实际字段类型，不能照抄UBOLT_GUIDE的double写法。
- `NativePipeSupportStore`：根元素的 `SteelSectionProbeNativeSupports/PlacedPipeSupport` 单独JSON Payload，Version=1，保存类别、DN、原生类、父管/支架实例ID、实际ISO编号、描述及点坐标。原PipeSupportComponents记录由原Attach方法写在同一根元素上。

`PipeClampPreviewSession`集中处理九类确认，不在每个Builder重复EC写入。A1TEST调用相同Writer/Data/Elements/Graphics核心，继续保留更严格的试验选型和检查。扩展其他模块时复用这个边界，提供真实父管、离线局部几何、目标轴点和原材料回调；不要绕开源复核、事务与单位检查。

## 预览、失败和撤销

正式页面预览通过COM暂态容器显示图形副本。为使用现有可靠的GetElementByID64桥接，在同一短事务内物化普通Cell、创建暂态副本、立即删除该临时Cell；这对Add/Delete不能跨事务拆开，也不能在中间写材料数据。预览更新先建新显示，再释放旧显示；Reset失败仍保存所有权，取消/关闭可重试回收。

原生确认事务中只创建最终原生根元素；预览释放只涉及暂态容器，Undo不会恢复出没有会话管理的普通预览块。辅助线/参考来源确认时才重建普通Cell写入材料，也有失败回滚。参数变化、滑动、取消和离开页面继续由原会话管理；不要提前释放已失败清理的显示对象。
