## 窗口与尺寸

所有尺寸为 96 DPI 下的 WPF DIP，按宿主系统 DPI 映射设备像素；例如 150% 对应 600×1320 设备像素。

| 项目 | 规格 |
| --- | --- |
| 完整工作区 | 初始400×720、最小400×560，宽高随Bentley停靠/浮动区域；400×880为视觉参考 |
| 外框 | 使用Bentley原生框架，不另加圆角Region或WPF圆角窗口边框 |
| 窗口标题栏 | 使用Bentley原生标题、拖动、关闭及图钉；工作区隐藏页面自绘32标题行 |
| 模块头 | 63，14×14 网格、38 图标、15 标题、展示代号、中文路径、返回首页 |
| 共享底栏 | 46，状态点、状态、OPM、关闭；首页另有进入按钮 |
| 状态文本 | 10.5 字，14 行高，最多两行；超长省略，悬停显示完整原消息 |
| 参数区外边距 | 左16、上12、右10、下12，外层滚动条6 |
| 卡片 | 白底，1边框，圆角6；分区头35，内边距12，间距12 |
| 表单控件 | 输入/选择34高，字段名约12，底间距5，字段间距约11 |
| 操作按钮 | 普通32；最终确认/取消36；横向间隔6或8 |
| 数值和代号 | Consolas，正文 Segoe UI / Microsoft YaHei UI |

窗口尺寸由Bentley管理，MainWindow只按DPI提供初始/最小尺寸；页面切换不设置ClientSize或MaximumSize。新页面必须用 `Tag="prototype-v4"` 接入工作区；PageHost 不增加旧模块页的外边距，旧 HeaderRow 隐藏。NativePanelLayout隐藏共享PrototypeChrome的32窗口标题行并将父行改Auto，保留63模块头。已有Q1/Q2和首页由各自Tag处理标题。页面不另开窗口、不重复换算DPI。

## 布局与交互

模块页统一采用模块头、可滚动参数区、固定底部操作区、共享状态底栏。使用 Grid 的星号/Auto 行和卡片，不用绝对 Canvas 坐标排表单。控件可用双列；长字段名和复选项必须换行，不挤出窗口。按钮组最多三列，四按钮用两列两行；轴偏移长标签单独成行，输入与应用按钮另占一行。

点取、结束、更新、滑动、角度、取消、确认等现有命令完整保留。不得为套用原型而增加第二次点取、删除角度、改为自动确认或隐藏现有选项。说明和读数过长时可限制展示高度，但完整原文须在悬停或可滚动区域查看。

多类型的参数面板继续由原代码控制显示。N3/N4 共用 BracketPage，标题/代号只通过只读展示转换适配；原设备和跨距参数逻辑不变。Q2 类型4的调整角度入口始终按原条件保留。消防柜保留生成/统计两页签。

表格保留全部原列和绑定，内容必须能复制/读取。窄窗使用横向滚动；为列设置合理最小宽度，不能靠压缩到不可读或删除列来适配。不要改变表格只读、单元格选择、列调整等既有能力。
