# CEL 构件放置

2026-10-30方向与实时显示修正：切换视图失败时保留旧图并允许重试；预览显示失败不禁止放置，开始时独立验证真实离线单元。每次左键提交后刷新开放视图并恢复连续放置，正式件应当次显示。图片通过标准OLE Render复制到自有位图，不再用GDI+包装宿主图元文件句柄。

2026-10-30修正：预览为白色背景，按真实图形范围双轴居中并等比适配窗口；等轴/俯视只变换预览副本。使用GetPicture关闭背景，再复制为WPF图像，不依赖宿主视图背景。放置成功以模型重读和附加项核对为准，移除原COM包装IsNew假阴性；日志位于 `%LOCALAPPDATA%/SteelSectionProbe/logs/CelLibrary/latest.log`。

首页“建模”→“CEL 构件放置”。将 `地面冲洗水盘管.cel` 与 `SteelSectionProbe.dll` 放在同一目录；编译产物会自动带上该文件。也可以在页面中浏览其他 CEL 文件并刷新单元列表。库内可放置的三维单元来自实际读取，读取失败不会显示为“0 个”。

选择单元后，插件面板内显示真实几何预览。安装位置采用 CEL 自带原点，中心轴保持世界坐标 +Z，只允许绕世界 Z 轴旋转。角度和面板预览同步。若源单元本身的中心轴没有沿局部 +Z 建模，应先在 CEL 中修正单元方向。

点击开始放置后在模型中点取安装位置，左键放置一件并继续放置，右键结束。鼠标预览不会进入模型或材料数量；每次确认在同一事务内加入普通单元并写入附加项，失败回退。开始点取会放弃已有选择集。离开页面、关闭插件或切换文档会结束当前放置。

每个正式单元的最外层保存独立构件附加项，包括库文件名、单元名、类别、规格、绕 Z 角度、数量 1 和记录版本。它是普通 CEL 构件，使用插件自身的统计入口。统计以当前 DGN 中实际存在的带标记根实例为准；删除、复制、撤销后重新读取即可得到当前数量。复制件按实际模型和图元身份分别计数。

统计默认读取活动模型，可切换当前 DGN 的全部模型；不统计参考附件、不展开普通单元内部零件，不把库定义当已放置实例。导出基于最近一次成功读取的统计结果。

部署只需更新 DLL 和 CEL，不需要安装工作集 Schema。库文件放置后写入的几何保存在 DGN 中，替换 CEL 不会自动修改已经放置的构件。默认库路径按实际加载的插件 DLL 所在目录解析。

离线检查使用宿主替身验证业务和 WPF 页面；Bentley 原生预览、CEL 导入的单位/原点、鼠标暂态、放置附加项、撤销及保存重开效果，需要在 OPM 中试放核对。
