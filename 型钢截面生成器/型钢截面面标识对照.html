型钢截面面标识 · 图片与代码元素对照

把示意图上的 A–P 标识对应到 steel_sections 包中各类型钢几何构造函数的顶点 / 线段 / 圆弧

等边角钢 (Equal Angle)

steel_equal_angle_geometry.py · build_equal_angle_geometry()

代码本地坐标与图同向：外角/根部在原点 (0,0)，水平肢沿 +X，竖直肢沿 +Y。 顶点 vertices = ((0,0),(b,0),(b,t),(t,t),(t,b),(0,b))， 圆角半径 radii = (0, 0, r2, r1, r2, 0)。

标识名称代码元素
H外角 / 根部 (Heel / Outside Corner)顶点 v0 = (0,0)（尖锐外角）
A水平肢外表面 (Outer Face of Horizontal Leg)线 c0→c1 = v0→v1（y = 0）
E水平肢端面 / 趾部端面 (Toe Face 1)线 c1→c2.entry（x = b）
B水平肢内表面 (Inner Face of Horizontal Leg)线 c2.exit→c3.entry（y = t）
G根部内圆角 (Root Fillet)角 c3 的 r1 圆弧
D竖直肢内表面 (Inner Face of Vertical Leg)线 c3.exit→c4.entry（x = t）
F竖直肢端面 / 趾部端面 (Toe Face 2)线 c4.exit→c5.entry（y = b）
C竖直肢外表面 (Outer Face of Vertical Leg)线 c5.exit→c0.entry = v5→v0（x = 0）
圆弧总数 = 3（代码断言 arc_count == 3）：1 个 r1（G 根部圆角）＋ 2 个 r2（图中未单独标字母的两个趾部小圆角）。
两个 r2 圆弧在 c2 = (b,t)（E 与 B 之间）和 c4 = (t,b)（D 与 F 之间）；r2 = t/3。
H（v0）、v1=(b,0)、v5=(0,b) 均为尖角，图里只有 H 标了字母。

槽钢 (Channel)

steel_channel_geometry.py · build_channel_geometry()

本地原点在 腹板外表面 / 下翼缘面，开口朝 +X。H 高度、B 宽度、 tw 腹板厚、tf 翼缘厚、r 根部圆角。

标识名称代码元素
A腹板外表面 (Outer Face of Web)线 p9→p0（x = 0）
B腹板内表面 (Inner Face of Web)线 p4→p5（x = tw）
C上翼缘上表面 (Top Face of Upper Flange)线 p8→p9（y = h）
D上翼缘下表面 (Lower Face of Upper Flange)线 p6→p7（y = h − tf）
E下翼缘上表面 (Upper Face of Lower Flange)线 p2→p3（y = tf）
F下翼缘下表面 (Bottom Face of Lower Flange)线 p0→p1（y = 0）
G上翼缘端面 / 趾部端面 (Upper Flange Toe Face)线 p7→p8（x = b）
H下翼缘端面 / 趾部端面 (Lower Flange Toe Face)线 p1→p2（x = b）
I上翼缘与腹板内侧根部圆角圆弧 p5→p6，圆心 (tw+r, h−tf−r)
J下翼缘与腹板内侧根部圆角圆弧 p3→p4，圆心 (tw+r, tf+r)
K上侧外角 / 根部 (Upper Heel)点 p9 = (0, h)
L下侧外角 / 根部 (Lower Heel)点 p0 = (0, 0)
圆弧总数 = 2（arc_count == 2）：只有 I、J 两段真圆弧；其余 A–H 均为直线。
闭合顺序 p0→p1→…→p9→p0，即 L→F→H→E→J→B→I→D→G→C→A→L。
Z0（重心距）从腹板外表面即 A 所在平面 x = 0 量起（steel_channel_data.py）。

工字钢 (I-Beam)

steel_ibeam_geometry.py · build_ibeam_geometry()

本地原点在 截面形心：+X 右、+Y 上，half_b = B/2、 half_h = H/2、half_web = tw/2。 顶点 v0…v11 从右上角起逆时针。

标识名称代码元素
A上翼缘上表面 (Top Face of Top Flange)线 v0→v1（y = H/2）
I上翼缘左端面 (Left Edge Face of Top Flange)线 v1→v2 切线部分（x = −B/2）
B上翼缘下表面-左侧 (Lower Face, Left Side)线 c2.exit→c3.entry（1:6 斜线）
M上翼缘与腹板左侧根部圆角角 c3 的 r1 圆弧
G腹板左侧面 (Left Face of Web)线 c3.exit→c4.entry（x = −tw/2）
O下翼缘与腹板左侧根部圆角角 c4 的 r1 圆弧
D下翼缘上表面-左侧 (Upper Face, Left Side)线 c4.exit→c5.entry
K下翼缘左端面 (Left Edge Face of Bottom Flange)线 c5.exit→c6.entry（x = −B/2）
F下翼缘下表面 (Bottom Face of Bottom Flange)线 v6→v7（y = −H/2）
L下翼缘右端面 (Right Edge Face of Bottom Flange)线 c7.exit→c8.entry（x = +B/2）
E下翼缘上表面-右侧 (Upper Face, Right Side)线 c8.exit→c9.entry
P下翼缘与腹板右侧根部圆角角 c9 的 r1 圆弧
H腹板右侧面 (Right Face of Web)线 c9.exit→c10.entry（x = +tw/2）
N上翼缘与腹板右侧根部圆角角 c10 的 r1 圆弧
C上翼缘下表面-右侧 (Lower Face, Right Side)线 c10.exit→c11.entry
J上翼缘右端面 (Right Edge Face of Top Flange)线 c11.exit→c0.entry（x = +B/2）
圆弧总数 = 8（arc_count == 8）：4 个 r1 根部圆角（M/N/O/P）＋ 4 个 r2 翼缘端部下侧小圆角（图中画成圆角但未标字母）。r2 位置为 v2 / v5 / v8 / v11。
B/C 与 D/E 之所以分左右且为斜线，是因为翼缘有 1:6 坡度：flange_thicknesses() 把根部算成 tf + extension/12、端部算成 tf − extension/12（extension = (B − tw)/2）。
H 型钢（热轧 H，steel_hbeam_geometry.py）为平行翼缘：B/C 合并、D/E 合并、且只有 M/N/O/P 四处 r 圆角（arc_count == 4），没有 r2 端部圆角。
